## 🚀 571. Find Median Given Frequency of Numbers 🔒

### 📖 Problem

The median is the value separating the higher half from the lower half of a data sample.

Write a solution to report the median of all the numbers in the database after decompressing the `Numbers` table. Round the median to one decimal point.

---

### 📝 Example

```text
Input: 
Numbers table:
+-----+-----------+
| num | frequency |
+-----+-----------+
| 0   | 7         |
| 1   | 1         |
| 2   | 3         |
| 3   | 1         |
+-----+-----------+
Output: 
+--------+
| median |
+--------+
| 0.0    |
+--------+
Explanation: 
If we decompress the Numbers table, we will get [0, 0, 0, 0, 0, 0, 0, 1, 2, 2, 2, 3],
so the median is (0 + 0) / 2 = 0.
```
---

### 💡 Idea

We need to find the median without actually expanding the numbers according to their frequencies.

We can calculate the **cumulative frequency** for each number and use it to identify the middle position(s) in the decompressed dataset.

---

### 💻 Solution

```sql
WITH cumulative AS (
    SELECT
        num,
        frequency,
        SUM(frequency) OVER (ORDER BY num) AS cumulative_frequency,
        SUM(frequency) OVER () AS total_frequency
    FROM Numbers)
SELECT ROUND(AVG(num), 1) AS median
FROM cumulative
WHERE cumulative_frequency >= (total_frequency + 1) / 2
  AND cumulative_frequency - frequency < (total_frequency + 2) / 2;
```

---

### 🛠️ How It Works

1. Calculate the **cumulative frequency** for each number to know how many values have appeared up to that number.
2. Calculate the **total frequency**, which represents the total number of values after decompression.
3. Find the middle position for an odd-sized dataset or the two middle positions for an even-sized dataset.
4. The `WHERE` condition identifies the number(s) occupying those middle positions.
5. Use `AVG(num)` to calculate the median when there are two middle values.
6. Round the final median to **one decimal place**.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the numbers for the cumulative frequency calculation)*

**Space Complexity:** `O(n)` *(stores the cumulative frequency and total frequency for each distinct number)*
