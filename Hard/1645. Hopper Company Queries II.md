Return the result table ordered by `month` in **ascending** order, where `month` is the month's number (January is `1`, February is `2`, etc.).

### 💡 Idea

Generate all 12 months, calculate the available drivers for each month, then count the **distinct drivers** who accepted at least one ride in that month. Finally, calculate the percentage.

---

### 💻 Solution

```sql
WITH RECURSIVE months AS (
    SELECT 1 AS month
    UNION ALL
    SELECT month + 1
    FROM months
    WHERE month < 12
),
available_drivers AS (
    SELECT m.month,
    COUNT(d.driver_id) AS available_drivers
    FROM months m
    LEFT JOIN Drivers d ON d.join_date < DATE_ADD(
            DATE_FORMAT(CONCAT('2020-', m.month, '-01'), '%Y-%m-01'),
            INTERVAL 1 MONTH)
    GROUP BY m.month
),
working_drivers AS (
    SELECT
    MONTH(r.requested_at) AS month,
    COUNT(DISTINCT ar.driver_id) AS working_drivers
    FROM Rides r
    JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY MONTH(r.requested_at)
)
SELECT
    m.month,
    ROUND(
        CASE WHEN ad.available_drivers = 0 THEN 0
        ELSE COALESCE(wd.working_drivers, 0) * 100.0 / ad.available_drivers
        END, 2) AS working_percentage
FROM months m
JOIN available_drivers ad ON m.month = ad.month
LEFT JOIN working_drivers wd ON m.month = wd.month
ORDER BY m.month;
```

---

### 🛠️ How It Works

1. Generate months `1` through `12`.
2. Count drivers who joined before the start of the following month to get the available drivers.
3. Join `Rides` with `AcceptedRides` to identify accepted rides.
4. Count `DISTINCT driver_id` for each month so a driver is counted only once even if they accepted multiple rides.
5. Calculate the percentage of working drivers among available drivers.
6. If there are no available drivers, return `0`.
7. Round the percentage to 2 decimal places.

---

### ⏱️ Complexity

**Time Complexity:** `O(M × D + R)` *(where `M = 12`, `D` is the number of drivers, and `R` is the number of rides)*

**Space Complexity:** `O(M + R)` *(for monthly and intermediate grouped results)*
