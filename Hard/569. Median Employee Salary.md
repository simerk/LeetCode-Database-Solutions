## 🚀 569. Median Employee Salary 🔒

### 📖 Problem

Write a solution to find the rows that contain the median salary of each company. While calculating the median, when you sort the salaries of the company, break the ties by `id`.

Return the result table in **any order**.

---

---

### 💡 Idea

We need to find the employee(s) whose salary falls exactly at the **median position** for each company.

We can use `ROW_NUMBER()` to order employees by salary, breaking salary ties using `id`, and then compare each employee's position with the middle position(s).

---

### 💻 Solution

```sql
WITH ranked AS (
    SELECT *,
    ROW_NUMBER() OVER (PARTITION BY company ORDER BY salary, id) AS rn,
    COUNT(*) OVER (PARTITION BY company) AS total_employees
    FROM Employee)
SELECT id, company, salary
FROM ranked
WHERE rn IN (FLOOR((total_employees + 1) / 2), CEIL((total_employees + 1) / 2)
);
```

---

### 🛠️ How It Works

1. Rank employees within each company by `salary`, using `id` to break salary ties.
2. Count the total number of employees in each company.
3. For an odd number of employees, select the single middle position.
4. For an even number of employees, select the two middle positions.
5. Return the employees occupying those median positions.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting employees within each company for the window functions)*

**Space Complexity:** `O(n)` *(stores the ranked employee records and window-function results)*
