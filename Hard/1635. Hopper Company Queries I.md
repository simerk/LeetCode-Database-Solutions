## 🚀 1635. Hopper Company Queries I 🔒

### 📖 Problem

Write a solution to report the following statistics for each month of `2020`:

- The number of drivers currently with the Hopper company by the end of the month (`active_drivers`).
- The number of accepted rides in that month (`accepted_rides`).
  
Return the result table ordered by `month` in **ascending** order, where `month` is the month's number (January is `1`, February is `2`, etc.).

### 💡 Idea

Generate all 12 months of 2020, then calculate the two statistics separately:

* Count drivers who joined on or before the end of each month.
* Count accepted rides whose request date falls within that month.

Finally, join both results with the 12 months so months with zero rides are included.

---

### 💻 Solution

```sql
WITH RECURSIVE months AS (
    SELECT 1 AS month
    UNION ALL
    SELECT month + 1
    FROM months
    WHERE month < 12
),
active_drivers AS (
    SELECT m.month,
    COUNT(d.driver_id) AS active_drivers
    FROM months m
    LEFT JOIN Drivers d
        ON d.join_date < DATE_ADD(
            DATE_FORMAT(CONCAT('2020-', m.month, '-01'), '%Y-%m-01'),
            INTERVAL 1 MONTH)
    GROUP BY m.month
),
accepted_rides AS (
    SELECT
    MONTH(r.requested_at) AS month,
    COUNT(*) AS accepted_rides
    FROM Rides r
    JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY MONTH(r.requested_at)
)
SELECT m.month, ad.active_drivers,
COALESCE(ar.accepted_rides, 0) AS accepted_rides
FROM months m
JOIN active_drivers ad ON m.month = ad.month
LEFT JOIN accepted_rides ar ON m.month = ar.month
ORDER BY m.month;
```

---

### 🛠️ How It Works

1. The recursive CTE generates months `1` through `12`.
2. For each month, count drivers whose `join_date` is before the next month's start, meaning they were active by the end of that month.
3. Join `Rides` with `AcceptedRides` to keep only accepted rides.
4. Filter accepted rides to those requested during 2020 and group them by month.
5. `LEFT JOIN` keeps all 12 months, while `COALESCE()` changes months with no accepted rides to `0`.
6. Sort the final result by month.

---

### ⏱️ Complexity

**Time Complexity:** `O(M × D + R)` *(where `M = 12`, `D` is the number of drivers, and `R` is the number of rides)*

**Space Complexity:** `O(M + R)` *(for the generated months and intermediate grouped results)*
