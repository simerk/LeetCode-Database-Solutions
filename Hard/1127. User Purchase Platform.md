## 🚀 1127. User Purchase Platform 🔒

### 📖 Problem

Write a solution to find the total number of users and the total amount spent using the mobile only, the desktop only, and both mobile and desktop together for each date.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Spending table:
+---------+------------+----------+--------+
| user_id | spend_date | platform | amount |
+---------+------------+----------+--------+
| 1       | 2019-07-01 | mobile   | 100    |
| 1       | 2019-07-01 | desktop  | 100    |
| 2       | 2019-07-01 | mobile   | 100    |
| 2       | 2019-07-02 | mobile   | 100    |
| 3       | 2019-07-01 | desktop  | 100    |
| 3       | 2019-07-02 | desktop  | 100    |
+---------+------------+----------+--------+
Output: 
+------------+----------+--------------+-------------+
| spend_date | platform | total_amount | total_users |
+------------+----------+--------------+-------------+
| 2019-07-01 | desktop  | 100          | 1           |
| 2019-07-01 | mobile   | 100          | 1           |
| 2019-07-01 | both     | 200          | 1           |
| 2019-07-02 | desktop  | 100          | 1           |
| 2019-07-02 | mobile   | 100          | 1           |
| 2019-07-02 | both     | 0            | 0           |
+------------+----------+--------------+-------------+ 
Explanation: 
• On 2019-07-01, user 1 purchased using both desktop and mobile,
user 2 purchased using mobile only and user 3 purchased using desktop only.
• On 2019-07-02, user 2 purchased using mobile only,
user 3 purchased using desktop only and no one purchased using both platforms.
```
---

### 💡 Idea

We need to classify each user on each date as **mobile only**, **desktop only**, or **both**.

First, generate every combination of date and platform so that all required rows are present. Then calculate each user's spending behavior per date and aggregate the users and amounts into the three platform categories.

---

### 💻 Solution

```sql
WITH dates AS (
    SELECT DISTINCT spend_date FROM Spending),
platforms AS (
    SELECT 'desktop' AS platform
    UNION ALL
    SELECT 'mobile'
    UNION ALL
    SELECT 'both'),
user_platform AS (
    SELECT spend_date, user_id,
    SUM(platform = 'mobile') AS mobile,
    SUM(platform = 'desktop') AS desktop,
    SUM(amount) AS amount
    FROM Spending
    GROUP BY spend_date, user_id),
classified AS (
    SELECT spend_date, user_id, amount,
    CASE WHEN mobile > 0 AND desktop > 0 THEN 'both'
    WHEN mobile > 0 THEN 'mobile'
    ELSE 'desktop' END AS platform
    FROM user_platform),
result AS (
    SELECT spend_date, platform,
    SUM(amount) AS total_amount,
    COUNT(*) AS total_users
    FROM classified
    GROUP BY spend_date, platform)
SELECT d.spend_date, p.platform,
COALESCE(r.total_amount, 0) AS total_amount,
COALESCE(r.total_users, 0) AS total_users
FROM dates d
CROSS JOIN platforms p
LEFT JOIN result r ON d.spend_date = r.spend_date AND p.platform = r.platform;
```

---

### 🛠️ How It Works

1. Get every unique spending date.
2. Create the three required platforms: `desktop`, `mobile`, and `both`.
3. Group spending by user and date.
4. Check whether each user used mobile, desktop, or both.
5. Classify each user into one platform category.
6. Calculate total amount and users for each date and platform.
7. Use `CROSS JOIN` to ensure every date has all three platform rows.
8. Use `COALESCE` to show `0` when no user belongs to a category.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(groups and aggregates the Spending records)*

**Space Complexity:** `O(n)` *(stores the intermediate user-date classifications)*
