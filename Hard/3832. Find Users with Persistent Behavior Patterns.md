## 🚀 3832. Find Users with Persistent Behavior Patterns

### 📖 Problem

Write a solution to identify **behaviorally stable users** based on the following definition:

- A user is considered **behaviorally stable** if there exists a sequence of **at least** `5` **consecutive days** such that:
  - The user performed **exactly one action per day** during that period.
  - The **action is the same** on all those consecutive days.
- If a user has multiple qualifying sequences, only consider the sequence with the **maximum length**.

Return the result table ordered by `streak_length` in ***descending*** order, then by `user_id` in ***ascending*** order.

---

### 📝 Example

```text
Input:
activity table:
+---------+-------------+--------+
| user_id | action_date | action |
+---------+-------------+--------+
| 1       | 2024-01-01  | login  |
| 1       | 2024-01-02  | login  |
| 1       | 2024-01-03  | login  |
| 1       | 2024-01-04  | login  |
| 1       | 2024-01-05  | login  |
| 1       | 2024-01-06  | logout |
| 2       | 2024-01-01  | click  |
| 2       | 2024-01-02  | click  |
| 2       | 2024-01-03  | click  |
| 2       | 2024-01-04  | click  |
| 3       | 2024-01-01  | view   |
| 3       | 2024-01-02  | view   |
| 3       | 2024-01-03  | view   |
| 3       | 2024-01-04  | view   |
| 3       | 2024-01-05  | view   |
| 3       | 2024-01-06  | view   |
| 3       | 2024-01-07  | view   |
+---------+-------------+--------+
Output:
+---------+--------+---------------+------------+------------+
| user_id | action | streak_length | start_date | end_date   |
+---------+--------+---------------+------------+------------+
| 3       | view   | 7             | 2024-01-01 | 2024-01-07 |
| 1       | login  | 5             | 2024-01-01 | 2024-01-05 |
+---------+--------+---------------+------------+------------+
Explanation:
• User 1:
  • Performed 'login' from 2024-01-01 to 2024-01-05 on consecutive days
  • Each day has exactly one action, and the action is the same
  • Streak length = 5 (meets minimum requirement)
  • The action changes on 2024-01-06, ending the streak
• User 2:
  • Performed 'click' for only 4 consecutive days
  • Does not meet the minimum streak length of 5
  • Excluded from the result
• User 3:
  • Performed 'view' for 7 consecutive days
  • This is the longest valid sequence for this user
  • Included in the result
The Results table is ordered by streak_length in descending order, then by user_id in ascending order
```

---

### 💡 Idea

* First, keep only the days where each user performed exactly one action.
* Use `ROW_NUMBER()` and `DATE_SUB()` to group consecutive days with the same action into streaks.
* Calculate the start date, end date, and length of each streak.
* Keep only streaks with at least 5 consecutive days.
* For each user, select their longest qualifying streak.
* Sort the final result by `streak_length` descending and `user_id` ascending.

---

### 💻 Solution

```sql
WITH single_action_days AS (
    SELECT user_id, action_date, MIN(action) AS action
    FROM activity
    GROUP BY user_id, action_date
    HAVING COUNT(*) = 1),
streak_groups AS (
    SELECT *,
    DATE_SUB(action_date,
    INTERVAL ROW_NUMBER() OVER (PARTITION BY user_id, action ORDER BY action_date) DAY
    ) AS grp
    FROM single_action_days),
streaks AS (
    SELECT user_id, action,
    MIN(action_date) AS start_date,
    MAX(action_date) AS end_date,
    COUNT(*) AS streak_length
    FROM streak_groups
    GROUP BY user_id, action, grp),
ranked AS (
    SELECT *,
    ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY streak_length DESC, start_date ASC) AS rn
    FROM streaks
    WHERE streak_length >= 5)
SELECT user_id, action, streak_length, start_date, end_date 
FROM ranked 
WHERE rn = 1 
ORDER BY streak_length DESC, user_id ASC;
```

---

### 🛠️ How It Works

1. **`single_action_days` CTE** keeps only user-days where exactly one action was performed.
2. **`streak_groups` CTE** uses `ROW_NUMBER()` with `DATE_SUB()` to assign the same group to consecutive dates with the same action.
3. **`streaks` CTE** groups these rows to find each streak's start date, end date, and length.
4. **`ranked` CTE** ranks qualifying streaks for each user by length, with the earliest start date as the tie-breaker.
5. Only streaks with a length of at least `5` are considered.
6. The final query selects the longest qualifying streak for each user and orders the results as required.

---

### ⏱️ Complexity

* **Time Complexity:** `O(n log n)` — due to grouping and window-function ordering.
* **Space Complexity:** `O(n)` — for the intermediate CTEs and window-function results.
