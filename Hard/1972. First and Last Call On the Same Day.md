## 🚀 1972. First and Last Call On the Same Day 🔒

### 📖 Problem

Write a solution to report the IDs of the users whose first and last calls on **any day** were with **the same person**. Calls are counted regardless of being the caller or the recipient.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Calls table:
+-----------+--------------+---------------------+
| caller_id | recipient_id | call_time           |
+-----------+--------------+---------------------+
| 8         | 4            | 2021-08-24 17:46:07 |
| 4         | 8            | 2021-08-24 19:57:13 |
| 5         | 1            | 2021-08-11 05:28:44 |
| 8         | 3            | 2021-08-17 04:04:15 |
| 11        | 3            | 2021-08-17 13:07:00 |
| 8         | 11           | 2021-08-17 22:22:22 |
+-----------+--------------+---------------------+
Output: 
+---------+
| user_id |
+---------+
| 1       |
| 4       |
| 5       |
| 8       |
+---------+
Explanation: 
On 2021-08-24, the first and last call of this day for user 8 was with user 4. User 8 should be included in the answer.
Similarly, user 4 on 2021-08-24 had their first and last call with user 8. User 4 should be included in the answer.
On 2021-08-11, user 1 and 5 had a call. This call was the only call for both of them on this day.
Since this call is the first and last call of the day for both of them, they should both be included in the answer.
```
---

### 💡 Idea

* Treat every call as a call for **both users**, regardless of who was the caller.
* For each user and day, find their first and last call times.
* Join back to the call records to identify the person involved in those calls.
* Keep users whose first and last calls were with the **same person**.

---

### 💻 Solution

```sql
WITH user_calls AS (
    SELECT caller_id AS user_id, recipient_id AS other_id, call_time FROM Calls
    UNION ALL
    SELECT recipient_id AS user_id, caller_id AS other_id, call_time FROM Calls
),
first_last AS (
    SELECT user_id,
    DATE(call_time) AS call_date,
    MIN(call_time) AS first_call,
    MAX(call_time) AS last_call
    FROM user_calls
    GROUP BY user_id, DATE(call_time)
)
SELECT DISTINCT f.user_id
FROM first_last f
JOIN user_calls c1
    ON f.user_id = c1.user_id
    AND f.first_call = c1.call_time
JOIN user_calls c2
    ON f.user_id = c2.user_id
    AND f.last_call = c2.call_time
    AND c1.other_id = c2.other_id;
```

---

### 🛠️ How It Works

1. `user_calls` creates a record for each user involved in every call.
2. Group by user and date to find the **first** and **last** call of each day.
3. Join those timestamps back to `user_calls` to find the people involved.
4. Compare the first and last call recipients.
5. Keep the user when both calls were with the same person.
6. `DISTINCT` prevents duplicate user IDs.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(grouping and joining the normalized call records)*

**Space Complexity:** `O(n)` *(for the normalized call records and intermediate results)*
