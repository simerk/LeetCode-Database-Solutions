## 🚀 1225. Report Contiguous Dates 🔒

### 📖 Problem

A system is running one task every day. Every task is independent of the previous tasks. The tasks can fail or succeed.

Write a solution to report the `period_state` for each continuous interval of days in the period from `2019-01-01` to `2019-12-31`.

`period_state` is `'failed'` if tasks in this interval failed or `'succeeded'` if tasks in this interval succeeded. Interval of days are retrieved as `start_date` and `end_date`.

Return the result table ordered by `start_date`.

---

### 📝 Example
```text
Input: 
Succeeded table:           Failed table:
+-------------------+      +-------------------+
| success_date      |      | fail_date         |
+-------------------+      +-------------------+
| 2018-12-30        |      | 2018-12-28        |
| 2018-12-31        |      | 2018-12-29        |
| 2019-01-01        |      | 2019-01-04        |
| 2019-01-02        |      | 2019-01-05        |
| 2019-01-03        |      +-------------------+
| 2019-01-06        |
+-------------------+
Output: 
+--------------+--------------+--------------+
| period_state | start_date   | end_date     |
+--------------+--------------+--------------+
| succeeded    | 2019-01-01   | 2019-01-03   |
| failed       | 2019-01-04   | 2019-01-05   |
| succeeded    | 2019-01-06   | 2019-01-06   |
+--------------+--------------+--------------+
Explanation: 
The report ignored the system state in 2018 as we care about the system in the period 2019-01-01 to 2019-12-31.
From 2019-01-01 to 2019-01-03 all tasks succeeded and the system state was "succeeded".
From 2019-01-04 to 2019-01-05 all tasks failed and the system state was "failed".
From 2019-01-06 to 2019-01-06 all tasks succeeded and the system state was "succeeded".
```
---

### 💡 Idea

We need to find continuous intervals of **failed** or **succeeded** days between `2019-01-01` and `2019-12-31`.

Combine both tables into one timeline, then use the difference between the date and its row number to identify consecutive dates belonging to the same state.

---

### 💻 Solution

```sql
WITH all_dates AS (
    SELECT fail_date AS date, 'failed' AS period_state
    FROM Failed
    WHERE fail_date BETWEEN '2019-01-01' AND '2019-12-31'
    UNION ALL
    SELECT success_date AS date, 'succeeded' AS period_state
    FROM Succeeded
    WHERE success_date BETWEEN '2019-01-01' AND '2019-12-31'),
grouped_dates AS (
    SELECT period_state, date,
    DATE_SUB(date, INTERVAL ROW_NUMBER() OVER (PARTITION BY period_state ORDER BY date) DAY) AS grp
    FROM all_dates)
SELECT period_state,
MIN(date) AS start_date,
MAX(date) AS end_date
FROM grouped_dates
GROUP BY period_state, grp
ORDER BY start_date;
```

---

### 🛠️ How It Works

1. Combine failed and succeeded dates into one table.
2. Keep only dates within the 2019 period.
3. Assign a row number separately for each state.
4. Subtract the row number from each date.
5. Consecutive dates with the same state produce the same grouping value.
6. Group by state and this calculated value.
7. Use `MIN()` and `MAX()` to get each interval's start and end dates.
8. Order the intervals by `start_date`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(dates are sorted for the window function)*

**Space Complexity:** `O(n)` *(stores the combined and ranked dates)*
