## 🚀 3764. Most Common Course Pairs

### 📖 Problem

Write a solution to identify **skill mastery pathways** by analyzing course completion sequences among top-performing students:

- Consider only **top-performing students** (those who completed **at least** `5` courses with an **average rating** of `4` or higher).
- For each top performer, identify the **sequence of courses** they completed in chronological order.
- Find all **consecutive course pairs** (`Course A → Course B`) taken by these students.
- Return the **pair frequency**, identifying which course transitions are most common among high achievers.

Return the result table ordered by pair frequency in ***descending*** order and then by first course name and second course name in ***ascending*** order.

### 💡 Idea

The goal is to identify the **most common consecutive course transitions** among **top-performing students**.

A top-performing student is someone who:

- Completed at least **5 courses**.
- Has an average course rating of **4 or higher**.

For each qualifying student:

- Arrange their completed courses in chronological order.
- Form consecutive course pairs (`Course A → Course B`).
- Count how many times each transition occurs across all top performers.

---

### 💻 MySQL Solution

```sql
WITH top_students AS (
    SELECT user_id,
    COUNT(DISTINCT course_name) AS courses, 
    AVG(course_rating) AS average_rating
    FROM course_completions
    GROUP BY user_id
    HAVING courses >= 5 AND average_rating >= 4),
ordered_courses AS (
    SELECT cc.user_id, cc.course_name as first_course,
    LEAD(course_name) OVER (PARTITION BY cc.user_id ORDER BY completion_date) AS second_course
    FROM course_completions cc
    JOIN top_students ts ON cc.user_id = ts.user_id)
SELECT first_course, second_course,
COUNT(*) AS transition_count
FROM ordered_courses
WHERE second_course IS NOT NULL
GROUP BY first_course, second_course
ORDER BY transition_count DESC, first_course ASC, second_course ASC;
```

---

### 🛠️ How It Works

1. The `top_students` CTE finds users who have:
   - Completed at least **5 courses**.
   - An average rating of at least **4**.
2. The `ordered_courses` CTE keeps only these users and uses `LEAD()` to get the next course completed by each student in chronological order.
3. Each row now represents a transition:
   - `first_course → second_course`
4. Remove the last course of each student using `WHERE second_course IS NOT NULL`.
5. Group by each course pair and count how many students followed that transition.
6. Sort the results by transition count (descending), then by first and second course names.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)`

- Sorting each user's courses for the window function dominates the complexity.

**Space Complexity:** `O(n)`

- Used to store the intermediate CTE results.
