## 🚀 1651. Hopper Company Queries III 🔒

### 📖 Problem

Write a solution to compute the `average_ride_distance` and `average_ride_duration` of every 3-month window starting from **January - March 2020** to **October - December 2020**. Round `average_ride_distance` and `average_ride_duration` to the nearest **two decimal places**.

The `average_ride_distance` is calculated by summing up the total `ride_distance` values from the three months and dividing it by `3`. The `average_ride_duration` is calculated in a similar way.

Return the result table ordered by `month` in **ascending** order, where `month` is the starting month's number (January is `1`, February is `2`, etc.).

### 💡 Idea

Generate all months from `1` to `12`, calculate the total ride distance and duration for each month, including months with no rides, and then use a 3-month moving window to calculate the averages.

---

### 💻 Solution

```sql
WITH RECURSIVE months AS (
    SELECT 1 AS month
    UNION ALL
    SELECT month + 1
    FROM months
    WHERE month < 12
),
monthly_rides AS (
    SELECT
        MONTH(r.requested_at) AS month,
        SUM(ar.ride_distance) AS ride_distance,
        SUM(ar.ride_duration) AS ride_duration
    FROM Rides r
    JOIN AcceptedRides ar ON r.ride_id = ar.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY MONTH(r.requested_at)
),
monthly_data AS (
    SELECT m.month,
    COALESCE(mr.ride_distance, 0) AS ride_distance,
    COALESCE(mr.ride_duration, 0) AS ride_duration
    FROM months m
    LEFT JOIN monthly_rides mr ON m.month = mr.month
),
rolling_data AS (
    SELECT month,
    SUM(ride_distance) OVER (ORDER BY month ROWS BETWEEN CURRENT ROW AND 2 FOLLOWING) AS total_distance,
    SUM(ride_duration) OVER (ORDER BY month ROWS BETWEEN CURRENT ROW AND 2 FOLLOWING) AS total_duration
    FROM monthly_data
)
SELECT month,
ROUND(total_distance / 3, 2) AS average_ride_distance,
ROUND(total_duration / 3, 2) AS average_ride_duration
FROM rolling_data
WHERE month <= 10
ORDER BY month;
```

---

### 🛠️ How It Works

1. Generate months `1` through `12`.
2. Calculate the total accepted ride distance and duration for each month.
3. `LEFT JOIN` with all months so months without rides have `0`.
4. Use a window function to sum the current month and the next two months.
5. Divide each 3-month total by `3` to get the average.
6. Keep months `1` through `10`, since each needs three months in its window.
7. Round both averages to 2 decimal places.

---

### ⏱️ Complexity

**Time Complexity:** `O(R + M log M)` *(processes rides and sorts the 12 monthly records for the window function)*

**Space Complexity:** `O(M + R)` *(for monthly aggregation and intermediate results)*
