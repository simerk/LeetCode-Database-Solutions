## 🚀 1336. Number of Transactions per Visit 🔒

### 📖 Problem

A bank wants to draw a chart of the number of transactions bank visitors did in one visit to the bank and the corresponding number of visitors who have done this number of transaction in one visit.

Write a solution to find how many users visited the bank and didn't do any transactions, how many visited the bank and did one transaction, and so on.

The result table will contain two columns:

- `transactions_count` which is the number of transactions done in one visit.
- `visits_count` which is the corresponding number of users who did `transactions_count` in one visit to the bank.

`transactions_count` should take all values from `0` to `max(transactions_count)` done by one or more users.

Return the result table ordered by `transactions_count`.

---

### 📝 Example
```text
Input: 
Visits table:                 Transactions table:
+---------+------------+      +---------+------------------+--------+
| user_id | visit_date |      | user_id | transaction_date | amount |
+---------+------------+      +---------+------------------+--------+
| 1       | 2020-01-01 |      | 1       | 2020-01-02       | 120    |
| 2       | 2020-01-02 |      | 2       | 2020-01-03       | 22     |
| 12      | 2020-01-01 |      | 7       | 2020-01-11       | 232    |
| 19      | 2020-01-03 |      | 1       | 2020-01-04       | 7      |
| 1       | 2020-01-02 |      | 9       | 2020-01-25       | 33     |
| 2       | 2020-01-03 |      | 9       | 2020-01-25       | 66     |
| 1       | 2020-01-04 |      | 8       | 2020-01-28       | 1      |
| 7       | 2020-01-11 |      | 9       | 2020-01-25       | 99     |
| 9       | 2020-01-25 |      +---------+------------------+--------+
| 8       | 2020-01-28 |
+---------+------------+
Output: 
+--------------------+--------------+
| transactions_count | visits_count |
+--------------------+--------------+
| 0                  | 4            |
| 1                  | 5            |
| 2                  | 0            |
| 3                  | 1            |
+--------------------+--------------+
Explanation: The chart drawn for this example is shown above.
* For transactions_count = 0, The visits (1, "2020-01-01"), (2, "2020-01-02"), (12, "2020-01-01") and (19, "2020-01-03") did no transactions so visits_count = 4.
* For transactions_count = 1, The visits (2, "2020-01-03"), (7, "2020-01-11"), (8, "2020-01-28"), (1, "2020-01-02") and (1, "2020-01-04") did one transaction so visits_count = 5.
* For transactions_count = 2, No customers visited the bank and did two transactions so visits_count = 0.
* For transactions_count = 3, The visit (9, "2020-01-25") did three transactions so visits_count = 1.
* For transactions_count >= 4, No customers visited the bank and did more than three transactions so we will stop at transactions_count = 3
```
---

### 💡 Idea

First count the transactions for each visit using a `LEFT JOIN`, so visits with no transactions get `0`. Then use a **recursive CTE** to generate every transaction count from `0` to the maximum count. Finally, count how many visits fall into each transaction count.

---

### 💻 Solution

```sql
WITH RECURSIVE visit_transactions AS (
    SELECT v.user_id, v.visit_date,
    COUNT(t.transaction_date) AS transactions_count
    FROM Visits v
    LEFT JOIN Transactions t ON v.user_id = t.user_id AND v.visit_date = t.transaction_date
    GROUP BY v.user_id, v.visit_date
),
transaction_counts AS (
    SELECT 0 AS transactions_count
    UNION ALL
    SELECT transactions_count + 1
    FROM transaction_counts
    WHERE transactions_count < (SELECT MAX(transactions_count) FROM visit_transactions)
)
SELECT tc.transactions_count,
COUNT(vt.transactions_count) AS visits_count
FROM transaction_counts tc
LEFT JOIN visit_transactions vt ON tc.transactions_count = vt.transactions_count
GROUP BY tc.transactions_count
ORDER BY tc.transactions_count;
```

---

### 🛠️ How It Works

1. `visit_transactions` counts transactions for every visit.
2. `LEFT JOIN` ensures visits with no transactions receive a count of `0`.
3. The recursive CTE generates all numbers from `0` to the maximum transaction count.
4. Join these counts with the visit results.
5. `COUNT()` gives the number of visits for each transaction count.
6. The `LEFT JOIN` ensures counts with **zero visits** are still included.

---

### ⏱️ Complexity

**Time Complexity:** `O(V + T + V log V)` *(processes visits and transactions and performs grouping)*

**Space Complexity:** `O(V + M)` *(stores visit counts and the generated transaction-count range)*
