## 🚀 578. Get Highest Answer Rate Question 🔒

### 📖 Problem

The **answer rate** for a question is the number of times a user answered the question by the number of times a user showed the question.

Write a solution to report the question that has the highest **answer rate**. If multiple questions have the same maximum **answer rate**, report the question with the **smallest** `question_id`.

---

### 📝 Example

```text
Input: 
SurveyLog table:
+----+--------+-------------+-----------+-------+-----------+
| id | action | question_id | answer_id | q_num | timestamp |
+----+--------+-------------+-----------+-------+-----------+
| 5  | show   | 285         | null      | 1     | 123       |
| 5  | answer | 285         | 124124    | 1     | 124       |
| 5  | show   | 369         | null      | 2     | 125       |
| 5  | skip   | 369         | null      | 2     | 126       |
+----+--------+-------------+-----------+-------+-----------+
Output: 
+------------+
| survey_log |
+------------+
| 285        |
+------------+
Explanation: 
Question 285 was showed 1 time and answered 1 time. The answer rate of question 285 is 1.0
Question 369 was showed 1 time and was not answered. The answer rate of question 369 is 0.0
Question 285 has the highest answer rate.
```

## 🚀 578. Get Highest Answer Rate Question

### 💡 Idea

We need to find the question with the **highest answer rate**.

The answer rate is calculated as:

**number of answers ÷ number of times the question was shown**

We can use conditional aggregation to count `show` and `answer` actions for each question, calculate the rate, and then select the question with the highest rate. In case of a tie, choose the smallest `question_id`.

---

### 💻 Solution

```sql
SELECT question_id AS survey_log
FROM SurveyLog
GROUP BY question_id
ORDER BY
    SUM(action = 'answer') / SUM(action = 'show') DESC,
    question_id ASC
LIMIT 1;
```

---

### 🛠️ How It Works

1. Group all records by `question_id`.
2. Count `answer` actions and `show` actions using conditional aggregation.
3. Divide the number of answers by the number of shows to get the answer rate.
4. Sort by answer rate in descending order.
5. If multiple questions have the same rate, sort by `question_id` in ascending order.
6. `LIMIT 1` returns the question with the highest answer rate.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(groups the survey records and sorts the questions by answer rate)*

**Space Complexity:** `O(n)` *(stores the grouped results for each question)*
