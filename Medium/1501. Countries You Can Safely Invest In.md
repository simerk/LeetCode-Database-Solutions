## 🚀 1501. Countries You Can Safely Invest In 🔒

### 📖 Problem

A telecommunications company wants to invest in new countries. The company intends to invest in the countries where the average call duration of the calls in this country is strictly greater than the global average call duration.

Write a solution to find the countries where this company can invest.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Calls table:                            Person table:                       Country table:
+-----------+-----------+----------+    +----+----------+--------------+    +----------+--------------+
| caller_id | callee_id | duration |    | id | name     | phone_number |    | name     | country_code |
+-----------+-----------+----------+    +----+----------+--------------+    +----------+--------------+
| 1         | 9         | 33       |    | 3  | Jonathan | 051-1234567  |    | Peru     | 051          |
| 2         | 9         | 4        |    | 12 | Elvis    | 051-7654321  |    | Israel   | 972          |
| 1         | 2         | 59       |    | 1  | Moncef   | 212-1234567  |    | Morocco  | 212          |
| 3         | 12        | 102      |    | 2  | Maroua   | 212-6523651  |    | Germany  | 049          |
| 3         | 12        | 330      |    | 7  | Meir     | 972-1234567  |    | Ethiopia | 251          |
| 12        | 3         | 5        |    | 9  | Rachel   | 972-0011100  |    +----------+--------------+
| 7         | 9         | 13       |    +----+----------+--------------+
| 7         | 1         | 3        |
| 9         | 7         | 1        |
| 1         | 7         | 7        |
+-----------+-----------+----------+
Output: 
+----------+
| country  |
+----------+
| Peru     |
+----------+
Explanation: 
• The average call duration for Peru is (102 + 102 + 330 + 330 + 5 + 5) / 6 = 145.666667
• The average call duration for Israel is (33 + 4 + 13 + 13 + 3 + 1 + 1 + 7) / 8 = 9.37500
• The average call duration for Morocco is (33 + 4 + 59 + 59 + 3 + 7) / 6 = 27.5000 
• Global call duration average = (2 * (33 + 4 + 59 + 102 + 330 + 5 + 13 + 3 + 1 + 7)) / 20 = 55.70000
• Since Peru is the only country where the average call duration is greater than the global average,
it is the only recommended country.
```
---

### 💡 Idea

Each call contributes its duration to **both the caller's and callee's country**. First calculate the average duration for every country, then compare it with the global average call duration.

---

### 💻 Solution

```sql
WITH country_calls AS (
    SELECT c.name AS country, ca.duration
    FROM Calls ca
    JOIN Person p ON ca.caller_id = p.id
    JOIN Country c ON LEFT(p.phone_number, 3) = c.country_code
    UNION ALL
    SELECT c.name AS country, ca.duration
    FROM Calls ca
    JOIN Person p ON ca.callee_id = p.id
    JOIN Country c ON LEFT(p.phone_number, 3) = c.country_code),
country_avg AS (
    SELECT country, AVG(duration) AS avg_duration
    FROM country_calls
    GROUP BY country),
global_avg AS (
    SELECT AVG(duration) AS avg_duration FROM Calls)
SELECT ca.country FROM country_avg ca
CROSS JOIN global_avg ga
WHERE ca.avg_duration > ga.avg_duration;
```

---

### 🛠️ How It Works

1. Match each caller to their country and record the call duration.
2. Do the same for each callee, using `UNION ALL`.
3. Calculate the average call duration for each country.
4. Calculate the global average duration directly from `Calls`.
5. Return countries whose average is strictly greater than the global average.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(calls are processed for both caller and callee)*

**Space Complexity:** `O(n)` *(the intermediate country-call data is stored)*
