## 🚀 612. Shortest Distance in a Plane 🔒

### 📖 Problem

The distance between two points `p1(x1, y1) and p2(x2, y2) is sqrt((x2 - x1)2 + (y2 - y1)2)`.

Write a solution to report the shortest distance between any two points from the `Point2D` table. Round the distance to **two decimal points**.

---

### 📝 Example

```text
Input: 
Point2D table:
+----+----+
| x  | y  |
+----+----+
| -1 | -1 |
| 0  | 0  |
| -1 | -2 |
+----+----+
Output: 
+----------+
| shortest |
+----------+
| 1.00     |
+----------+
Explanation: The shortest distance is 1.00 from point (-1, -1) to (-1, 2).
```
---

### 💡 Idea

We need to find the **minimum Euclidean distance** between any two points.

Use a **self-join** to compare every pair of different points, calculate their distance using `SQRT()` and `POW()`, then find the minimum distance.

---

### 💻 Solution

```sql
SELECT ROUND(
    MIN(
        SQRT(
            POW(p1.x - p2.x, 2) +
            POW(p1.y - p2.y, 2))
    ),2) AS shortest
FROM Point2D p1
JOIN Point2D p2 ON p1.x != p2.x OR p1.y != p2.y;
```

---

### 🛠️ How It Works

1. Self-join `Point2D` to compare points with each other.
2. Exclude comparing a point with itself.
3. Calculate the Euclidean distance for each pair.
4. Use `MIN()` to find the shortest distance.
5. Round the result to 2 decimal places.

---

### ⏱️ Complexity

**Time Complexity:** `O(n²)` *(compares every pair of points)*

**Space Complexity:** `O(n²)` *(the self-join can produce up to `n²` point pairs)*
