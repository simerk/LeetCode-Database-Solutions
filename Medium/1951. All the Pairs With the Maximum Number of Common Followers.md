## 🚀 1951. All the Pairs With the Maximum Number of Common Followers 🔒

### 📖 Problem

Write a solution to find all the pairs of users with the maximum number of common followers. In other words, if the maximum number of common followers between any two users is `maxCommon`, then you have to return all pairs of users that have `maxCommon` common followers.

The result table should contain the pairs `user1_id` and `user2_id` where `user1_id < user2_id`.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Relations table:
+---------+-------------+
| user_id | follower_id |
+---------+-------------+
| 1       | 3           |
| 2       | 3           |
| 7       | 3           |
| 1       | 4           |
| 2       | 4           |
| 7       | 4           |
| 1       | 5           |
| 2       | 6           |
| 7       | 5           |
+---------+-------------+
Output: 
+----------+----------+
| user1_id | user2_id |
+----------+----------+
| 1        | 7        |
+----------+----------+
Explanation: 
Users 1 and 2 have two common followers (3 and 4).
Users 1 and 7 have three common followers (3, 4, and 5).
Users 2 and 7 have two common followers (3 and 4).
Since the maximum number of common followers between any two users is 3, we return all pairs of users with three common followers, which is only the pair (1, 7). We return the pair as (1, 7), not as (7, 1).
Note that we do not have any information about the users that follow users 3, 4, and 5, so we consider them to have 0 followers.
```
---

### 💡 Idea

* Create all possible pairs of users who appear in `Relations`.
* For each pair, count how many followers they have in common.
* Find the maximum common-follower count.
* Return every pair that has this maximum.
* Keep only `user1_id < user2_id` to avoid duplicate pairs.

---

### 💻 Solution

```sql
WITH users AS (
    SELECT DISTINCT user_id FROM Relations
),
common_followers AS (
    SELECT r1.user_id AS user1_id, r2.user_id AS user2_id,
    COUNT(*) AS common_followers
    FROM Relations r1
    JOIN Relations r2
        ON r1.follower_id = r2.follower_id
        AND r1.user_id < r2.user_id
    GROUP BY r1.user_id, r2.user_id
),
max_common AS (
    SELECT MAX(common_followers) AS max_followers
    FROM common_followers
)
SELECT user1_id, user2_id
FROM common_followers
WHERE common_followers = (SELECT max_followers FROM max_common);
```

---

### 🛠️ How It Works

1. Self-join `Relations` on `follower_id` to find users sharing the same follower.
2. `user1_id < user2_id` ensures each pair appears only once.
3. Count the shared followers for every pair.
4. Find the maximum number of common followers.
5. Return all pairs whose count equals that maximum.

Pairs with **0 common followers** are not included because the table only provides relationships for users with at least one follower.

---

### ⏱️ Complexity

**Time Complexity:** `O(n²)` *(due to the self-join on `Relations`)*

**Space Complexity:** `O(n)` *(for the intermediate grouped pairs)*
