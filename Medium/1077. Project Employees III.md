## 🚀 1077. Project Employees III 🔒

### 📖 Problem

Write a solution to report the **most experienced** employees in each project. In case of a tie, report all employees with the maximum number of experience years.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Project table:                         Employee table:
+-------------+-------------+          +-------------+--------+------------------+
| project_id  | employee_id |          | employee_id | name   | experience_years |
+-------------+-------------+          +-------------+--------+------------------+
| 1           | 1           |          | 1           | Khaled | 3                |
| 1           | 2           |          | 2           | Ali    | 2                |
| 1           | 3           |          | 3           | John   | 3                |
| 2           | 1           |          | 4           | Doe    | 2                |
| 2           | 4           |          +-------------+--------+------------------+
+-------------+-------------+
Output: 
+-------------+---------------+
| project_id  | employee_id   |
+-------------+---------------+
| 1           | 1             |
| 1           | 3             |
| 2           | 1             |
+-------------+---------------+
Explanation: Both employees with id 1 and 3 have the most experience among the employees of the first project.
For the second project, the employee with id 1 has the most experience.
```
---

### 💡 Idea

We need to find the **most experienced employee(s) in each project**.

First, join `Project` with `Employee` to get the experience of each employee in every project. Then find the maximum experience for each project and return all employees who have that experience.

---

### 💻 Solution

```sql id="r6n2vc"
WITH project_experience AS (
    SELECT p.project_id, p.employee_id, e.experience_years
    FROM Project p
    JOIN Employee e ON p.employee_id = e.employee_id),
max_experience AS (
    SELECT project_id, MAX(experience_years) AS max_years
    FROM project_experience
    GROUP BY project_id)
SELECT pe.project_id, pe.employee_id
FROM project_experience pe
JOIN max_experience me
ON pe.project_id = me.project_id AND pe.experience_years = me.max_years;
```

---

### 🛠️ How It Works

1. Join `Project` with `Employee` to get each employee's experience.
2. Find the maximum experience for every project.
3. Join the maximum experience back to the project records.
4. Return all employees whose experience equals the project maximum.
5. This automatically includes all employees in case of a tie.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(processes the project and employee records through joins and grouping)*

**Space Complexity:** `O(k)` *(stores the maximum experience for each project)*
