## 🚀 3601. Find Drivers with Improved Fuel Efficiency

### 📖 Problem

Write a solution to find drivers whose **fuel efficiency has improved** by **comparing** their average fuel efficiency in the **first half** of the year with the **second half** of the year.

- Calculate **fuel efficiency** as `distance_km / fuel_consumed` for **each** trip
- **First half:** January to June, **Second half:** July to December
- Only include drivers who have trips in **both halves** of the year
- Calculate the **efficiency improvement** as (`second_half_avg - first_half_avg`)
- **Round** all results to `2` decimal places
Return the result table ordered by `efficiency improvement` in **descending** order, then by `driver name` in **ascending** order.
---

### 💡 Idea

The goal is to compare each driver's **average fuel efficiency** in the first and second halves of the year.

Fuel efficiency for each trip is calculated as:

> **distance_km / fuel_consumed**

We first calculate each driver's average fuel efficiency for the **first half (January–June)** and **second half (July–December)** using a CTE. Then, we compare the two averages and return only those drivers whose fuel efficiency improved in the second half.

---

## 💻 Solution

```sql
WITH average AS (
    SELECT driver_id, 
    AVG(CASE WHEN MONTH(trip_date) <= 6 THEN distance_km / fuel_consumed END) AS first_half,
    AVG(CASE WHEN MONTH(trip_date) > 6 THEN distance_km / fuel_consumed END) AS second_half
    FROM trips
    GROUP BY driver_id)
SELECT
a.driver_id, d.driver_name,
ROUND(a.first_half, 2) AS first_half_avg,
ROUND(a.second_half, 2) AS second_half_avg,
ROUND(a.second_half - a.first_half, 2) AS efficiency_improvement
FROM average a
INNER JOIN drivers d ON a.driver_id = d.driver_id
WHERE a.first_half IS NOT NULL AND a.second_half IS NOT NULL AND a.second_half > a.first_half
ORDER BY efficiency_improvement DESC, driver_name;
```

---

### 🛠️ How It Works

1. The `average` CTE calculates each driver's average fuel efficiency for the **first half** and **second half** of the year using `CASE` inside `AVG()`.
2. Join the CTE with the `drivers` table to retrieve the driver's name.
3. Round both averages to **2 decimal places** using `ROUND()`.
4. Calculate the efficiency improvement as **second_half − first_half**.
5. Keep only drivers who have trips in both halves of the year and whose fuel efficiency improved.
6. Sort the result by efficiency improvement (descending) and driver name (ascending).

---


### ⏱️ Complexity

**Time Complexity:** `O(n)`

- `n` = number of rows in the `trips` table.

**Space Complexity:** `O(n)`

- Used to store the aggregated results for each driver in the CTE.
