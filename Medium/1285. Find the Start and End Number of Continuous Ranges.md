## 🚀 1285. Find the Start and End Number of Continuous Ranges 🔒

### 📖 Problem

Write a solution to find the start and end number of continuous ranges in the table `Logs`.

Return the result table ordered by `start_id`.

---

### 📝 Example
```text
Input: 
Logs table:
+------------+
| log_id     |
+------------+
| 1          |
| 2          |
| 3          |
| 7          |
| 8          |
| 10         |
+------------+
Output: 
+------------+--------------+
| start_id   | end_id       |
+------------+--------------+
| 1          | 3            |
| 7          | 8            |
| 10         | 10           |
+------------+--------------+
Explanation: 
The result table should contain all ranges in table Logs.
From 1 to 3 is contained in the table.
From 4 to 6 is missing in the table
From 7 to 8 is contained in the table.
Number 9 is missing from the table.
Number 10 is contained in the table.
```
---

### 💡 Idea

A new range starts whenever the current `log_id` is **not consecutive** to the previous one. We can use `LAG()` to compare each ID with the previous ID, assign a group to each continuous range, and then find the minimum and maximum ID of each group.

---

### 💻 Solution

```sql
WITH marked_logs AS (
    SELECT log_id,
    CASE WHEN log_id - LAG(log_id) OVER (ORDER BY log_id) = 1 THEN 0
    ELSE 1 END AS new_group
    FROM Logs),
grouped_logs AS (
    SELECT log_id,
    SUM(new_group) OVER (ORDER BY log_id) AS grp
    FROM marked_logs)
SELECT
MIN(log_id) AS start_id,
MAX(log_id) AS end_id
FROM grouped_logs
GROUP BY grp
ORDER BY start_id;
```

---

### 🛠️ How It Works

1. `LAG()` gets the previous `log_id` for each row.
2. If the current ID is consecutive, mark it as part of the same range; otherwise, start a new group.
3. A cumulative `SUM()` creates a unique group for each continuous range.
4. `MIN()` and `MAX()` give the start and end of each range.
5. Sort the final result by `start_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the log IDs for the window functions)*

**Space Complexity:** `O(n)` *(stores intermediate window-function results)*
