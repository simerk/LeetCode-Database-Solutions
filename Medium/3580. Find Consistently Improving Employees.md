## 🚀 3580. Find Consistently Improving Employees

### 💡 Idea

The goal is to find employees whose **last three performance reviews** show a **strictly increasing** trend.

We first rank each employee's reviews by **review date in descending order** so that the most recent review gets rank `1`. Then, we keep only the latest three reviews, compare their ratings, and calculate the improvement score as:

> **Latest Rating − Earliest Rating**

Finally, we return only those employees whose ratings are strictly increasing.

---

## 💻 Solution

```sql
WITH ranked_reviews AS (
    SELECT employee_id, review_date, rating,
    ROW_NUMBER() OVER (PARTITION BY employee_id ORDER BY review_date DESC) AS rn
    FROM performance_reviews
)
SELECT e.employee_id, e.name,
MAX(CASE WHEN rr.rn = 1 THEN rr.rating END) -
MAX(CASE WHEN rr.rn = 3 THEN rr.rating END) AS improvement_score
FROM ranked_reviews rr
JOIN employees e ON rr.employee_id = e.employee_id
WHERE rr.rn <= 3
GROUP BY e.employee_id, e.name
HAVING COUNT(*) = 3
AND MAX(CASE WHEN rr.rn = 1 THEN rr.rating END) > MAX(CASE WHEN rr.rn = 2 THEN rr.rating END)
AND MAX(CASE WHEN rr.rn = 2 THEN rr.rating END) > MAX(CASE WHEN rr.rn = 3 THEN rr.rating END)
ORDER BY improvement_score DESC, name ASC;
```

---

### 🛠️ How It Works

1. Use `ROW_NUMBER()` to rank each employee's reviews from the most recent to the oldest.
2. Keep only the latest **3 reviews** (`rn <= 3`).
3. Use `CASE` inside `MAX()` to retrieve the ratings of the latest, second latest, and third latest reviews.
4. Keep only employees with exactly **3 reviews** whose ratings are strictly increasing over time.
5. Calculate the improvement score as **latest rating − earliest rating** and sort the result.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)`

- Ranking the reviews requires sorting within each employee.

**Space Complexity:** `O(n)`

- Used to store the ranked reviews in the CTE.
