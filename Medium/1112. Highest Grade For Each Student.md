## 🚀 1112. Highest Grade For Each Student 🔒

### 📖 Problem

Write a solution to find the highest grade with its corresponding course for each student. In case of a tie, you should find the course with the smallest `course_id`.

Return the result table ordered by `student_id` in **ascending** order.

---

### 📝 Example
```text
Input: 
Enrollments table:
+------------+-------------------+
| student_id | course_id | grade |
+------------+-----------+-------+
| 2          | 2         | 95    |
| 2          | 3         | 95    |
| 1          | 1         | 90    |
| 1          | 2         | 99    |
| 3          | 1         | 80    |
| 3          | 2         | 75    |
| 3          | 3         | 82    |
+------------+-----------+-------+
Output: 
+------------+-------------------+
| student_id | course_id | grade |
+------------+-----------+-------+
| 1          | 2         | 99    |
| 2          | 2         | 95    |
| 3          | 3         | 82    |
+------------+-----------+-------+
```
---

### 💡 Idea

We need to find the **highest grade for each student**. If a student has the same highest grade in multiple courses, we choose the course with the **smallest `course_id`**.

We can use `ROW_NUMBER()` to rank each student's courses by grade descending and course ID ascending, then select the first row.

---

### 💻 Solution

```sql
WITH ranked_grades AS (
    SELECT student_id, course_id, grade,
    ROW_NUMBER() OVER (PARTITION BY student_id ORDER BY grade DESC, course_id ASC) AS rn
    FROM Enrollments)
SELECT student_id, course_id, grade
FROM ranked_grades
WHERE rn = 1
ORDER BY student_id;
```

---

### 🛠️ How It Works

1. Partition the rows by `student_id`.
2. Rank courses by `grade` in descending order.
3. Use `course_id` ascending to break ties.
4. `ROW_NUMBER()` assigns rank `1` to the desired course.
5. Keep only `rn = 1` for each student.
6. Order the final result by `student_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(ranking requires sorting the courses within each student)*

**Space Complexity:** `O(n)` *(stores the ranked rows)*
