## 🚀 580. Count Student Number in Departments 🔒

### 📖 Problem

Write a solution to report the respective department name and number of students majoring in each department for all departments in the `Department` table (even ones with no current students).

Return the result table ordered by `student_number` in **descending** order. In case of a tie, order them by `dept_name` **alphabetically**.

---

### 📝 Example

```text
Input: 
Student table:                                          Department table:
+------------+--------------+--------+---------+        +---------+-------------+
| student_id | student_name | gender | dept_id |        | dept_id | dept_name   |
+------------+--------------+--------+---------+        +---------+-------------+
| 1          | Jack         | M      | 1       |        | 1       | Engineering |
| 2          | Jane         | F      | 1       |        | 2       | Science     |
| 3          | Mark         | M      | 2       |        | 3       | Law         |
+------------+--------------+--------+---------+        +---------+-------------+
Output: 
+-------------+----------------+
| dept_name   | student_number |
+-------------+----------------+
| Engineering | 2              |
| Science     | 1              |
| Law         | 0              |
+-------------+----------------+
```

## 🚀 580. Count Student Number in Departments

### 💡 Idea

We need to count the number of students in **every department**, including departments with **no students**.

A `LEFT JOIN` is used so that all departments are retained. `COUNT(student_id)` counts the students, while departments without students get a count of `0`.

---

### 💻 Solution

```sql
SELECT d.dept_name, COUNT(s.student_id) AS student_number
FROM Department d
LEFT JOIN Student s ON d.dept_id = s.dept_id
GROUP BY d.dept_id, d.dept_name
ORDER BY student_number DESC, d.dept_name ASC;
```

---

### 🛠️ How It Works

1. Start with the `Department` table so every department is included.
2. Use `LEFT JOIN` to match students to their departments.
3. Count `student_id` for each department.
4. Departments without students get `0`.
5. Group the results by department.
6. Sort by student count descending, then department name alphabetically.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(scans the department and student records and performs the join)*

**Space Complexity:** `O(n + m)` *(stores the grouped/joined results, depending on the execution plan)*
