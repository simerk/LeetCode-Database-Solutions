## 🚀 1454. Active Users 🔒

### 📖 Problem

**Active users** are those who logged in to their accounts for five or more consecutive days.

Write a solution to find the id and the name of **active users**.

Return the result table **ordered** by `id`.

---

### 📝 Example
```text
Input: 
Logins table:            Accounts table:
+----+------------+      +----+----------+
| id | login_date |      | id | name     |
+----+------------+      +----+----------+
| 7  | 2020-05-30 |      | 1  | Winston  |
| 1  | 2020-05-30 |      | 7  | Jonathan |
| 7  | 2020-05-31 |      +----+----------+
| 7  | 2020-06-01 |
| 7  | 2020-06-02 |
| 7  | 2020-06-02 |
| 7  | 2020-06-03 |
| 1  | 2020-06-07 |
| 7  | 2020-06-10 |
+----+------------+
Output: 
+----+----------+
| id | name     |
+----+----------+
| 7  | Jonathan |
+----+----------+
Explanation: 
User Winston with id = 1 logged in 2 times only in 2 different days, so, Winston is not an active user.
User Jonathan with id = 7 logged in 7 times in 6 different days, five of them were consecutive days, so, Jonathan is an active user.
```
---

### 💡 Idea

Remove duplicate login dates first, then use `LAG()` to find consecutive days. We can group consecutive dates using the difference between `login_date` and its row number, and identify users with at least 5 days in the same group.

---

### 💻 Solution

```sql
WITH distinct_logins AS (
    SELECT DISTINCT id, login_date FROM Logins),
grouped_logins AS (
    SELECT id, login_date,
    DATE_SUB(login_date,
      INTERVAL ROW_NUMBER() OVER (PARTITION BY id ORDER BY login_date) DAY
    ) AS grp
    FROM distinct_logins),
active_users AS (
    SELECT id FROM grouped_logins
    GROUP BY id, grp
    HAVING COUNT(*) >= 5)
SELECT DISTINCT a.id, a.name
FROM Accounts a
JOIN active_users au ON a.id = au.id
ORDER BY a.id;
```

---

### 🛠️ How It Works

1. Remove duplicate logins on the same day for each user.
2. Assign a row number to each user's login dates in chronological order.
3. Subtract the row number from the login date; consecutive dates produce the same `grp`.
4. Group by user and `grp` and keep groups containing at least 5 days.
5. Join with `Accounts` to get the user's name.
6. Order the result by `id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting login dates for the window function)*

**Space Complexity:** `O(n)` *(for the CTEs and intermediate grouped results)*
