## 🚀 1747. Leetflex Banned Accounts 🔒

### 📖 Problem

Write a solution to find the `account_id` of the accounts that should be banned from Leetflex. An account should be banned if it was logged in at some moment from two different IP addresses.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
LogInfo table:
+------------+------------+---------------------+---------------------+
| account_id | ip_address | login               | logout              |
+------------+------------+---------------------+---------------------+
| 1          | 1          | 2021-02-01 09:00:00 | 2021-02-01 09:30:00 |
| 1          | 2          | 2021-02-01 08:00:00 | 2021-02-01 11:30:00 |
| 2          | 6          | 2021-02-01 20:30:00 | 2021-02-01 22:00:00 |
| 2          | 7          | 2021-02-02 20:30:00 | 2021-02-02 22:00:00 |
| 3          | 9          | 2021-02-01 16:00:00 | 2021-02-01 16:59:59 |
| 3          | 13         | 2021-02-01 17:00:00 | 2021-02-01 17:59:59 |
| 4          | 10         | 2021-02-01 16:00:00 | 2021-02-01 17:00:00 |
| 4          | 11         | 2021-02-01 17:00:00 | 2021-02-01 17:59:59 |
+------------+------------+---------------------+---------------------+
Output: 
+------------+
| account_id |
+------------+
| 1          |
| 4          |
+------------+
Explanation: 
Account ID 1 --> The account was active from "2021-02-01 09:00:00" to "2021-02-01 09:30:00" with two different IP addresses (1 and 2). It should be banned.
Account ID 2 --> The account was active from two different addresses (6, 7) but in two different times.
Account ID 3 --> The account was active from two different addresses (9, 13) on the same day but they do not intersect at any moment.
Account ID 4 --> The account was active from "2021-02-01 17:00:00" to "2021-02-01 17:00:00" with two different IP addresses (10 and 11). It should be banned.
```
---

### 💡 Idea

We need to find accounts that have **overlapping login sessions from different IP addresses**.

Join the `LogInfo` table with itself for the same account, make sure the IP addresses are different, and check whether the two time intervals overlap.

Two sessions overlap when one session starts before or exactly when the other session ends.

---

### 💻 Solution

```sql
SELECT DISTINCT l1.account_id
FROM LogInfo l1
JOIN LogInfo l2
    ON l1.account_id = l2.account_id
    AND l1.ip_address <> l2.ip_address
    AND l1.login <= l2.logout
    AND l2.login <= l1.logout;
```

---

### 🛠️ How It Works

1. Self-join `LogInfo` to compare login sessions within the same account.
2. `l1.ip_address <> l2.ip_address` ensures the IP addresses are different.
3. The two conditions on `login` and `logout` check whether the sessions overlap.
4. `DISTINCT` ensures each banned account appears only once.

---

### ⏱️ Complexity

**Time Complexity:** `O(n²)` *(compares login records within each account)*

**Space Complexity:** `O(n)` *(for the self-join result)*
