## 🚀 1126. Active Businesses 🔒

### 📖 Problem

The **average activity** for a particular `event_type` is the average `occurrences` across all companies that have this event.

An **active business** is a business that has **more than one** `event_type` such that their `occurrences` is **strictly greater** than the average activity for that event.

Write a solution to find all **active businesses**.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Events table:
+-------------+------------+-------------+
| business_id | event_type | occurrences |
+-------------+------------+-------------+
| 1           | reviews    | 7           |
| 3           | reviews    | 3           |
| 1           | ads        | 11          |
| 2           | ads        | 7           |
| 3           | ads        | 6           |
| 1           | page views | 3           |
| 2           | page views | 12          |
+-------------+------------+-------------+
Output: 
+-------------+
| business_id |
+-------------+
| 1           |
+-------------+
Explanation:  
The average activity for each event can be calculated as follows:
- 'reviews': (7+3)/2 = 5
- 'ads': (11+7+6)/3 = 8
- 'page views': (3+12)/2 = 7.5
The business with id=1 has 7 'reviews' events (more than 5) and 11 'ads' events (more than 8),
so it is an active business.
```
---

### 💡 Idea

We need to find businesses that have **more than one event type** where their `occurrences` are strictly greater than the **average occurrences for that event type**.

First, calculate the average occurrences for each `event_type`. Then compare every business's occurrences with the corresponding average and count how many event types exceed it.

---

### 💻 Solution

```sql
WITH event_avg AS (
    SELECT event_type,
    AVG(occurrences) AS avg_occurrences
    FROM Events
    GROUP BY event_type),
above_average AS (
    SELECT e.business_id, e.event_type
    FROM Events e
    JOIN event_avg a ON e.event_type = a.event_type
    WHERE e.occurrences > a.avg_occurrences)
SELECT business_id
FROM above_average
GROUP BY business_id
HAVING COUNT(*) > 1;
```

---

### 🛠️ How It Works

1. Calculate the average `occurrences` for each event type.
2. Join these averages back to the `Events` table.
3. Keep events where occurrences are strictly above their event average.
4. Group the qualifying events by `business_id`.
5. Keep businesses with more than one qualifying event type.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans and groups the Events table, then compares each event with its average)*

**Space Complexity:** `O(n)` *(stores the averages and above-average event records)*
