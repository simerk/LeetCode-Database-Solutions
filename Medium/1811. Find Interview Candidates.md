## 🚀 1811. Find Interview Candidates 🔒

### 📖 Problem

Write a solution to report the `name` and the `mail` of all **interview candidates**. A user is an **interview candidate** if **at least one** of these two conditions is true:

- The user won any medal in **three or more consecutive contests**.
- The user won the gold medal in **three or more different** contests (not necessarily consecutive).
  
Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Contests table:                                              Users table:
+------------+------------+--------------+--------------+    +---------+--------------------+-------+
| contest_id | gold_medal | silver_medal | bronze_medal |    | user_id | mail               | name  |
+------------+------------+--------------+--------------+    +---------+--------------------+-------+
| 190        | 1          | 5            | 2            |    | 1       | sarah@leetcode.com | Sarah |
| 191        | 2          | 3            | 5            |    | 2       | bob@leetcode.com   | Bob   |
| 192        | 5          | 2            | 3            |    | 3       | alice@leetcode.com | Alice |
| 193        | 1          | 3            | 5            |    | 4       | hercy@leetcode.com | Hercy |
| 194        | 4          | 5            | 2            |    | 5       | quarz@leetcode.com | Quarz |
| 195        | 4          | 2            | 1            |    +---------+--------------------+-------+
| 196        | 1          | 5            | 2            |
+------------+------------+--------------+--------------+
Output: 
+-------+--------------------+
| name  | mail               |
+-------+--------------------+
| Sarah | sarah@leetcode.com |
| Bob   | bob@leetcode.com   |
| Alice | alice@leetcode.com |
| Quarz | quarz@leetcode.com |
+-------+--------------------+
Explanation: 
Sarah won 3 gold medals (190, 193, and 196), so we include her in the result table.
Bob won a medal in 3 consecutive contests (190, 191, and 192), so we include him in the result table.
    - Note that he also won a medal in 3 other consecutive contests (194, 195, and 196).
Alice won a medal in 3 consecutive contests (191, 192, and 193), so we include her in the result table.
Quarz won a medal in 5 consecutive contests (190, 191, 192, 193, and 194), so we include them in the result table.
```
---

### 💡 Idea

There are two ways to qualify:

* Win a medal in **3 or more consecutive contests**.
* Win **gold in 3 or more different contests**.

We can first combine all medal winners into one table, then use `LAG()` to detect consecutive contest wins and a separate count for gold medals.

---

### 💻 Solution

```sql
WITH medal_winners AS (
    SELECT contest_id, gold_medal AS user_id FROM Contests
    UNION ALL
    SELECT contest_id, silver_medal FROM Contests
    UNION ALL
    SELECT contest_id, bronze_medal FROM Contests
),
distinct_medals AS (
    SELECT DISTINCT contest_id, user_id FROM medal_winners
),
consecutive AS (
    SELECT user_id, contest_id,
    contest_id - LAG(contest_id) OVER (PARTITION BY user_id ORDER BY contest_id) AS diff
    FROM distinct_medals
),
gold_winners AS (
    SELECT gold_medal AS user_id FROM Contests
    GROUP BY gold_medal
    HAVING COUNT(*) >= 3
),
qualified_medal AS (
    SELECT DISTINCT user_id
    FROM consecutive
    GROUP BY user_id, contest_id - ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY contest_id)
    HAVING COUNT(*) >= 3
)
SELECT u.name, u.mail
FROM Users u
WHERE u.user_id IN (
    SELECT user_id FROM gold_winners
    UNION
    SELECT user_id FROM qualified_medal);
```

---

### 🛠️ How It Works

1. `medal_winners` combines gold, silver, and bronze winners into one table.
2. `DISTINCT` prevents duplicate user-contest combinations.
3. `consecutive` orders each user's contests and identifies gaps between contests.
4. `ROW_NUMBER()` with `contest_id` creates groups of consecutive contests.
5. Groups containing at least 3 contests satisfy the consecutive-medal condition.
6. `gold_winners` finds users with at least 3 gold medals.
7. `UNION` combines both groups of qualifying users.
8. Join the qualifying IDs with `Users` to return their names and emails.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting contest records for the window functions)*

**Space Complexity:** `O(n)` *(stores the intermediate medal and grouping results)*
