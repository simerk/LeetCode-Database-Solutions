## 🚀 1549. The Most Recent Orders for Each Product 🔒

### 📖 Problem

Write a solution to find the most recent order(s) of each product.

Return the result table ordered by `product_name` in **ascending** order and in case of a tie by the `product_id` in **ascending** order. If there still a tie, order them by `order_id` in **ascending** order.

---

### 📝 Example

```text
Input: 
Orders table:                                         Customers table:             Products table:
+----------+------------+-------------+------------+  +-------------+-----------+  +------------+--------------+-------+
| order_id | order_date | customer_id | product_id |  | customer_id | name      |  | product_id | product_name | price |
+----------+------------+-------------+------------+  +-------------+-----------+  +------------+--------------+-------+
| 1        | 2020-07-31 | 1           | 1          |  | 1           | Winston   |  | 1          | keyboard     | 120   |
| 2        | 2020-07-30 | 2           | 2          |  | 2           | Jonathan  |  | 2          | mouse        | 80    |
| 3        | 2020-08-29 | 3           | 3          |  | 3           | Annabelle |  | 3          | screen       | 600   |
| 4        | 2020-07-29 | 4           | 1          |  | 4           | Marwan    |  | 4          | hard disk    | 450   |
| 5        | 2020-06-10 | 1           | 2          |  | 5           | Khaled    |  +------------+--------------+-------+
| 6        | 2020-08-01 | 2           | 1          |  +-------------+-----------+
| 7        | 2020-08-01 | 3           | 1          |
| 8        | 2020-08-03 | 1           | 2          |
| 9        | 2020-08-07 | 2           | 3          |
| 10       | 2020-07-15 | 1           | 2          |
+----------+------------+-------------+------------+
Output: 
+--------------+------------+----------+------------+
| product_name | product_id | order_id | order_date |
+--------------+------------+----------+------------+
| keyboard     | 1          | 6        | 2020-08-01 |
| keyboard     | 1          | 7        | 2020-08-01 |
| mouse        | 2          | 8        | 2020-08-03 |
| screen       | 3          | 3        | 2020-08-29 |
+--------------+------------+----------+------------+
Explanation: 
keyboard's most recent order is in 2020-08-01, it was ordered two times this day.
mouse's most recent order is in 2020-08-03, it was ordered only once this day.
screen's most recent order is in 2020-08-29, it was ordered only once this day.
The hard disk was never ordered and we do not include it in the result table.
```
---

### 💡 Idea

Use a window function to find the latest `order_date` for each product, then keep all orders that happened on that date.

---

### 💻 Solution

```sql
WITH latest_orders AS (
    SELECT o.product_id, o.order_id, o.order_date,
    MAX(o.order_date) OVER (PARTITION BY o.product_id) AS latest_date
    FROM Orders o)
SELECT p.product_name, p.product_id, l.order_id, l.order_date
FROM latest_orders l
JOIN Products p ON l.product_id = p.product_id
WHERE l.order_date = l.latest_date
ORDER BY p.product_name ASC, p.product_id ASC, l.order_id ASC;
```

---

### 🛠️ How It Works

1. `MAX(order_date) OVER (PARTITION BY product_id)` finds the latest order date for each product.
2. Keep only orders whose date matches that latest date.
3. This includes multiple orders when a product was ordered more than once on its latest date.
4. Join with `Products` to get the product name.
5. Sort by `product_name`, `product_id`, and `order_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(window processing and sorting)*

**Space Complexity:** `O(n)` *(for the CTE and intermediate results)*
