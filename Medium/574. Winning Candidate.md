## 🚀 574. Winning Candidate 🔒

### 📖 Problem

Write a solution to report the name of the winning candidate (i.e., the candidate who got the largest number of votes).

The test cases are generated so that exactly one candidate wins the elections.

---

### 📝 Example

```text
Input: 
Candidate table:       Vote table:
+----+------+          +----+-------------+
| id | name |          | id | candidateId |
+----+------+          +----+-------------+
| 1  | A    |          | 1  | 2           |
| 2  | B    |          | 2  | 4           |
| 3  | C    |          | 3  | 3           |
| 4  | D    |          | 4  | 2           |
| 5  | E    |          | 5  | 5           |
+----+------+          +----+-------------+
Output: 
+------+
| name |
+------+
| B    |
+------+
Explanation: 
Candidate B has 2 votes. Candidates C, D, and E have 1 vote each.
The winner is candidate B.
```
---

## 🚀 574. Winning Candidate

### 💡 Idea

We need to find the candidate who received the **most votes**.

We can count the votes for each candidate, sort them in descending order, and return the name of the candidate with the highest vote count.

---

### 💻 Solution

```sql
SELECT c.name FROM Candidate c
JOIN Vote v ON c.id = v.candidateId
GROUP BY c.id, c.name
ORDER BY COUNT(v.id) DESC
LIMIT 1;
```

---

### 🛠️ How It Works

1. Join `Candidate` and `Vote` using the candidate ID.
2. Group the votes by candidate.
3. Count how many votes each candidate received.
4. Sort candidates by vote count in descending order.
5. `LIMIT 1` returns the candidate with the most votes.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(groups the votes and sorts candidates by their vote count)*

**Space Complexity:** `O(n)` *(stores the grouped candidate results)*
