## 🚀 1613. Find the Missing IDs 🔒

### 📖 Problem

Write a solution to find the missing customer IDs. The missing IDs are ones that are not in the `Customers` table but are in the range between `1` and the **maximum** `customer_id` present in the table.

Notice that the maximum `customer_id` will not exceed `100`.

Return the result table ordered by `ids` in **ascending** order.

---

### 📝 Example

```text
Input: 
Customers table:
+-------------+---------------+
| customer_id | customer_name |
+-------------+---------------+
| 1           | Alice         |
| 4           | Bob           |
| 5           | Charlie       |
+-------------+---------------+
Output: 
+-----+
| ids |
+-----+
| 2   |
| 3   |
+-----+
Explanation: 
The maximum customer_id present in the table is 5, so in the range [1,5], IDs 2 and 3 are missing from the table.
```
---

### 💡 Idea

Generate all IDs from `1` to the maximum `customer_id` using a recursive CTE, then use a `LEFT JOIN` to find the IDs that do not exist in `Customers`.

---

### 💻 Solution

```sql
WITH RECURSIVE ids AS (
    SELECT 1 AS id
    UNION ALL
    SELECT id + 1
    FROM ids
    WHERE id < (SELECT MAX(customer_id) FROM Customers)
)
SELECT i.id AS ids
FROM ids i
LEFT JOIN Customers c ON i.id = c.customer_id
WHERE c.customer_id IS NULL
ORDER BY ids ASC;
```

---

### 🛠️ How It Works

1. The recursive CTE generates numbers from `1` to the maximum `customer_id`.
2. `LEFT JOIN` checks whether each generated ID exists in `Customers`.
3. IDs with no matching customer have `NULL` values.
4. Keep only these missing IDs.
5. Sort the result in ascending order.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(where `n` is the maximum customer ID, at most 100)*

**Space Complexity:** `O(n)` *(for the generated ID sequence)*
