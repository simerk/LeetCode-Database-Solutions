## 🚀 1132. Reported Posts II 🔒

### 📖 Problem

Write a solution to find the average daily percentage of posts that got removed after being reported as spam, **rounded to 2 decimal places**.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Actions table:                                             Removals table:
+---------+---------+-------------+--------+--------+      +---------+-------------+
| user_id | post_id | action_date | action | extra  |      | post_id | remove_date |
+---------+---------+-------------+--------+--------+      +---------+-------------+
| 1       | 1       | 2019-07-01  | view   | null   |      | 2       | 2019-07-20  |
| 1       | 1       | 2019-07-01  | like   | null   |      | 3       | 2019-07-18  |
| 1       | 1       | 2019-07-01  | share  | null   |      +---------+-------------+
| 2       | 2       | 2019-07-04  | view   | null   |
| 2       | 2       | 2019-07-04  | report | spam   |
| 3       | 4       | 2019-07-04  | view   | null   |
| 3       | 4       | 2019-07-04  | report | spam   |
| 4       | 3       | 2019-07-02  | view   | null   |
| 4       | 3       | 2019-07-02  | report | spam   |
| 5       | 2       | 2019-07-03  | view   | null   |
| 5       | 2       | 2019-07-03  | report | racism |
| 5       | 5       | 2019-07-03  | view   | null   |
| 5       | 5       | 2019-07-03  | report | racism |
+---------+---------+-------------+--------+--------+
Output: 
+-----------------------+
| average_daily_percent |
+-----------------------+
| 75.00                 |
+-----------------------+
Explanation: 
The percentage for 2019-07-04 is 50% because only one post of two spam reported posts were removed.
The percentage for 2019-07-02 is 100% because one post was reported as spam and it was removed.
The other days had no spam reports so the average is (50 + 100) / 2 = 75%
Note that the output is only one number and that we do not care about the remove dates.
```
---

### 💡 Idea

We need to calculate the **daily percentage of spam-reported posts that were removed**, then take the average of those daily percentages.

First, find the distinct posts reported as spam on each date. Then check which of those posts appear in `Removals`. Finally, calculate the percentage for each date and average the percentages.

---

### 💻 Solution

```sql id="8r6q2m"
WITH spam_reports AS (
    SELECT DISTINCT action_date, post_id
    FROM Actions
    WHERE action = 'report' AND extra = 'spam'),
daily_percentage AS (
    SELECT s.action_date,
    COUNT(r.post_id) * 100.0 / COUNT(s.post_id) AS percentage
    FROM spam_reports s
    LEFT JOIN Removals r ON s.post_id = r.post_id
    GROUP BY s.action_date)
SELECT ROUND(AVG(percentage), 2) AS average_daily_percent
FROM daily_percentage;
```

---

### 🛠️ How It Works

1. Filter only posts reported as `spam`.
2. Use `DISTINCT` so the same post is counted only once per day.
3. `LEFT JOIN` with `Removals` to identify which reported posts were removed.
4. Calculate the percentage of removed spam-reported posts for each day.
5. Average the daily percentages.
6. Round the final result to 2 decimal places.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans and aggregates the Actions and Removals records)*

**Space Complexity:** `O(n)` *(stores the intermediate spam report records)*
