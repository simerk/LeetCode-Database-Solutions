## 🚀 1440. Evaluate Boolean Expression 🔒

### 📖 Problem

Evaluate the boolean expressions in `Expressions` table.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Expressions table:                               Variables table:
+--------------+----------+---------------+      +------+-------+
| left_operand | operator | right_operand |      | name | value |
+--------------+----------+---------------+      +------+-------+
| x            | >        | y             |      | x    | 66    |
| x            | <        | y             |      | y    | 77    |
| x            | =        | y             |      +------+-------+
| y            | >        | x             |
| y            | <        | x             |
| x            | =        | x             |
+--------------+----------+---------------+
Output: 
+--------------+----------+---------------+-------+
| left_operand | operator | right_operand | value |
+--------------+----------+---------------+-------+
| x            | >        | y             | false |
| x            | <        | y             | true  |
| x            | =        | y             | false |
| y            | >        | x             | true  |
| y            | <        | x             | false |
| x            | =        | x             | true  |
+--------------+----------+---------------+-------+
Explanation: 
As shown, you need to find the value of each boolean expression in the table using the variables table.
```
---

### 💡 Idea

Join the `Expressions` table with `Variables` twice — once for the left operand and once for the right operand. Then use `CASE` to evaluate the operator.

---

### 💻 Solution

```sql
SELECT e.left_operand, e.operator, e.right_operand,
CASE
  WHEN e.operator = '>' AND l.value > r.value THEN 'true'
  WHEN e.operator = '<' AND l.value < r.value THEN 'true'
  WHEN e.operator = '=' AND l.value = r.value THEN 'true'
ELSE 'false' END AS value
FROM Expressions e
JOIN Variables l ON e.left_operand = l.name
JOIN Variables r ON e.right_operand = r.name;
```

---

### 🛠️ How It Works

1. Join `Variables` once to get the value of the left operand.
2. Join it again to get the value of the right operand.
3. Use `CASE` to evaluate `>`, `<`, or `=`.
4. Return `true` when the expression is satisfied; otherwise, return `false`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(each expression requires two variable lookups)*

**Space Complexity:** `O(n)` *(for the resulting rows)*
