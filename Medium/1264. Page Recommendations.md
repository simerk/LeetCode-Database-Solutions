## 🚀 1264. Page Recommendations 🔒

### 📖 Problem

Write a solution to recommend pages to the user with `user_id = 1` using the pages that your friends liked. It should not recommend pages you already liked.

Return result table in **any order** without duplicates.

---

### 📝 Example
```text
Input: 
Likes table:               Friendship table:
+---------+---------+      +----------+----------+
| user_id | page_id |      | user1_id | user2_id |
+---------+---------+      +----------+----------+
| 1       | 88      |      | 1        | 2        |
| 2       | 23      |      | 1        | 3        |
| 3       | 24      |      | 1        | 4        |
| 4       | 56      |      | 2        | 3        |
| 5       | 11      |      | 2        | 4        |
| 6       | 33      |      | 2        | 5        |
| 2       | 77      |      | 6        | 1        |
| 3       | 77      |      +----------+----------+
| 6       | 88      |
+---------+---------+
Output: 
+------------------+
| recommended_page |
+------------------+
| 23               |
| 24               |
| 56               |
| 33               |
| 77               |
+------------------+
Explanation: 
User one is friend with users 2, 3, 4 and 6.
Suggested pages are 23 from user 2, 24 from user 3, 56 from user 3 and 33 from user 6.
Page 77 is suggested from both user 2 and user 3.
Page 88 is not suggested because user 1 already likes it.
```
---

### 💡 Idea

Find all pages liked by **user 1's friends**, then remove the pages that **user 1 already likes**. Use `DISTINCT` to avoid duplicate recommendations.

---

### 💻 Solution

```sql
SELECT DISTINCT l.page_id AS recommended_page FROM Likes l
JOIN Friendship f ON l.user_id = f.user1_id OR l.user_id = f.user2_id
WHERE (f.user1_id = 1 OR f.user2_id = 1)
AND l.page_id NOT IN (
      SELECT page_id FROM Likes
      WHERE user_id = 1);
```

---

### 🛠️ How It Works

1. Find friendships where **user 1** is involved.
2. Get the pages liked by those friends.
3. Exclude pages already liked by user 1.
4. Use `DISTINCT` to remove duplicate recommendations.

---

### ⏱️ Complexity

**Time Complexity:** `O(F × L)` *(joins friendships with likes)*

**Space Complexity:** `O(P)` *(stores the distinct recommended pages)*
