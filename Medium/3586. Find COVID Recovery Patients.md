## 🚀 3586. Find COVID Recovery Patients

### 💡 Idea

The goal is to find patients who have **recovered from COVID**, meaning they had:

- At least one **Positive** test.
- A **Negative** test on a later date.

We first find each patient's **first positive test**. Then, we find the **first negative test that occurred after the positive test**. Finally, we calculate the recovery time as the number of days between these two dates.

---

## 💻 Solution

```sql
WITH first_positive AS (
    SELECT patient_id, MIN(test_date) AS first_positive_date
    FROM covid_tests
    WHERE result = 'Positive'
    GROUP BY patient_id),
first_negative AS (
    SELECT fp.patient_id, MIN(ct.test_date) AS first_negative_date
    FROM first_positive fp
    INNER JOIN covid_tests ct ON fp.patient_id = ct.patient_id
    WHERE ct.result = 'Negative'
    AND ct.test_date > fp.first_positive_date
    GROUP BY fp.patient_id)
SELECT p.patient_id, p.patient_name, p.age,
DATEDIFF(fn.first_negative_date,fp.first_positive_date) AS recovery_time
FROM patients p
INNER JOIN first_positive fp ON p.patient_id = fp.patient_id
INNER JOIN first_negative fn ON p.patient_id = fn.patient_id
ORDER BY recovery_time, patient_name
```

---

### 🛠️ How It Works

1. The `first_positive` CTE finds the **first positive test date** for each patient.
2. The `first_negative` CTE finds the **first negative test** that occurred **after** the first positive test.
3. Join both CTEs with the `patients` table.
4. Use `DATEDIFF()` to calculate the recovery time in days.
5. Sort the result by recovery time and patient name.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)`

- The test records are scanned to determine the first positive and first qualifying negative test.

**Space Complexity:** `O(n)`

- Used to store the intermediate CTE results.
