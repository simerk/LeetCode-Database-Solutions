## 🚀 1445. Apples & Oranges 🔒

### 📖 Problem

Write a solution to report the difference between the number of **apples** and **oranges** sold each day.

Return the result table **ordered** by `sale_date`.

---

### 📝 Example
```text
Input: 
Sales table:
+------------+------------+-------------+
| sale_date  | fruit      | sold_num    |
+------------+------------+-------------+
| 2020-05-01 | apples     | 10          |
| 2020-05-01 | oranges    | 8           |
| 2020-05-02 | apples     | 15          |
| 2020-05-02 | oranges    | 15          |
| 2020-05-03 | apples     | 20          |
| 2020-05-03 | oranges    | 0           |
| 2020-05-04 | apples     | 15          |
| 2020-05-04 | oranges    | 16          |
+------------+------------+-------------+
Output: 
+------------+--------------+
| sale_date  | diff         |
+------------+--------------+
| 2020-05-01 | 2            |
| 2020-05-02 | 0            |
| 2020-05-03 | 20           |
| 2020-05-04 | -1           |
+------------+--------------+
Explanation: 
Day 2020-05-01, 10 apples and 8 oranges were sold (Difference  10 - 8 = 2).
Day 2020-05-02, 15 apples and 15 oranges were sold (Difference 15 - 15 = 0).
Day 2020-05-03, 20 apples and 0 oranges were sold (Difference 20 - 0 = 20).
Day 2020-05-04, 15 apples and 16 oranges were sold (Difference 15 - 16 = -1).
```
---

### 💡 Idea

Group sales by `sale_date` and calculate the total apples minus the total oranges using conditional aggregation.

---

### 💻 Solution

```sql
SELECT sale_date,
SUM(CASE WHEN fruit = 'apples' THEN sold_num ELSE 0 END)
- SUM(CASE WHEN fruit = 'oranges' THEN sold_num ELSE 0 END) AS diff
FROM Sales
GROUP BY sale_date
ORDER BY sale_date;
```

---

### 🛠️ How It Works

1. Group all sales by `sale_date`.
2. Sum the number of apples sold for each day.
3. Sum the number of oranges sold for each day.
4. Subtract oranges from apples to get `diff`.
5. Order the result by `sale_date`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(each sales row is processed once)*

**Space Complexity:** `O(d)` *(stores one aggregated result per distinct sale date)*
