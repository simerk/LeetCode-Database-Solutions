## 🚀 1783. Grand Slam Titles 🔒

### 📖 Problem

Write a solution to report the number of grand slam tournaments won by each player. Do not include the players who did not win any tournament.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Players table:                 Championships table:
+-----------+-------------+    +------+-----------+---------+---------+---------+
| player_id | player_name |    | year | Wimbledon | Fr_open | US_open | Au_open |
+-----------+-------------+    +------+-----------+---------+---------+---------+
| 1         | Nadal       |    | 2018 | 1         | 1       | 1       | 1       |
| 2         | Federer     |    | 2019 | 1         | 1       | 2       | 2       |
| 3         | Novak       |    | 2020 | 2         | 1       | 2       | 2       |
+-----------+-------------+    +------+-----------+---------+---------+---------+
Output: 
+-----------+-------------+-------------------+
| player_id | player_name | grand_slams_count |
+-----------+-------------+-------------------+
| 2         | Federer     | 5                 |
| 1         | Nadal       | 7                 |
+-----------+-------------+-------------------+
Explanation: 
Player 1 (Nadal) won 7 titles: Wimbledon (2018, 2019), Fr_open (2018, 2019, 2020), US_open (2018), and Au_open (2018).
Player 2 (Federer) won 5 titles: Wimbledon (2020), US_open (2019, 2020), and Au_open (2019, 2020).
Player 3 (Novak) did not win anything, we did not include them in the result table.
```
---

### 💡 Idea

Each tournament column contains the `player_id` of its winner for that year.

Use `UNION ALL` to combine all four tournaments into one list of winners, then count the number of titles for each player.

---

### 💻 Solution

```sql
WITH winners AS (
    SELECT Wimbledon AS player_id FROM Championships
    UNION ALL
    SELECT Fr_open FROM Championships
    UNION ALL
    SELECT US_open FROM Championships
    UNION ALL
    SELECT Au_open FROM Championships)
SELECT p.player_id, p.player_name,
COUNT(*) AS grand_slams_count
FROM winners w
JOIN Players p ON w.player_id = p.player_id
GROUP BY p.player_id, p.player_name;
```

---

### 🛠️ How It Works

1. Collect Wimbledon winners from all years.
2. Add winners from the other three tournaments using `UNION ALL`.
3. Join the combined winners with `Players` to get player names.
4. `COUNT(*)` counts the total tournaments won by each player.
5. The `JOIN` automatically excludes players who never won a tournament.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(processes the four tournament columns across all years)*

**Space Complexity:** `O(n)` *(stores the combined winner records)*
