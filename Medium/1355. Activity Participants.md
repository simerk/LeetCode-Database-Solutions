## 🚀 1355. Activity Participants 🔒

### 📖 Problem

Find the names of all the activities with neither the maximum nor the minimum number of participants.

Each activity in the `Activities` table is performed by any person in the table Friends.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Friends table:                               Activities table:
+------+--------------+---------------+      +------+--------------+
| id   | name         | activity      |      | id   | name         |
+------+--------------+---------------+      +------+--------------+
| 1    | Jonathan D.  | Eating        |      | 1    | Eating       |
| 2    | Jade W.      | Singing       |      | 2    | Singing      |
| 3    | Victor J.    | Singing       |      | 3    | Horse Riding |
| 4    | Elvis Q.     | Eating        |      +------+--------------+  
| 5    | Daniel A.    | Eating        |
| 6    | Bob B.       | Horse Riding  |
+------+--------------+---------------+
Output: 
+--------------+
| activity     |
+--------------+
| Singing      |
+--------------+
Explanation: 
Eating activity is performed by 3 friends, maximum number of participants, (Jonathan D. , Elvis Q. and Daniel A.)
Horse Riding activity is performed by 1 friend, minimum number of participants, (Bob B.)
Singing is performed by 2 friends (Victor J. and Jade W.)
```
---

### 💡 Idea

Count the number of participants for each activity, then exclude activities whose participant count is either the **maximum or minimum**.

---

### 💻 Solution

```sql
WITH activity_counts AS (
    SELECT activity, COUNT(*) AS participants
    FROM Friends
    GROUP BY activity)
SELECT activity
FROM activity_counts
WHERE participants > (SELECT MIN(participants) FROM activity_counts)
  AND participants < (SELECT MAX(participants) FROM activity_counts);
```

---

### 🛠️ How It Works

1. Count the friends participating in each activity.
2. Find the minimum and maximum participant counts.
3. Keep only activities with counts strictly between the minimum and maximum.
4. Activities tied for either minimum or maximum are excluded.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(groups the friends by activity)*

**Space Complexity:** `O(a)` *(stores one count for each activity)*
