## 🚀 1107. New Users Daily Count 🔒

### 📖 Problem

Write a solution to reports for every date within at most `90` days from today, the number of users that logged in for the first time on that date. Assume today is `2019-06-30`.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Traffic table:
+---------+----------+---------------+
| user_id | activity | activity_date |
+---------+----------+---------------+
| 1       | login    | 2019-05-01    |
| 1       | homepage | 2019-05-01    |
| 1       | logout   | 2019-05-01    |
| 2       | login    | 2019-06-21    |
| 2       | logout   | 2019-06-21    |
| 3       | login    | 2019-01-01    |
| 3       | jobs     | 2019-01-01    |
| 3       | logout   | 2019-01-01    |
| 4       | login    | 2019-06-21    |
| 4       | groups   | 2019-06-21    |
| 4       | logout   | 2019-06-21    |
| 5       | login    | 2019-03-01    |
| 5       | logout   | 2019-03-01    |
| 5       | login    | 2019-06-21    |
| 5       | logout   | 2019-06-21    |
+---------+----------+---------------+
Output: 
+------------+-------------+
| login_date | user_count  |
+------------+-------------+
| 2019-05-01 | 1           |
| 2019-06-21 | 2           |
+------------+-------------+
Explanation: 
Note that we only care about dates with non zero user count.
The user with id 5 first logged in on 2019-03-01 so he's not counted on 2019-06-21.
```
---

### 💡 Idea

We need to find the **first login date** for every user, then count how many users had their first login within the **last 90 days** from `2019-06-30`.

First, find each user's earliest login date. Then filter those dates to the 90-day period and count users per date.

---

### 💻 Solution

```sql
WITH first_login AS (
    SELECT user_id,
    MIN(activity_date) AS login_date
    FROM Traffic
    WHERE activity = 'login'
    GROUP BY user_id)
SELECT login_date,
COUNT(*) AS user_count
FROM first_login
WHERE login_date BETWEEN '2019-04-02' AND '2019-06-30'
GROUP BY login_date;
```

---

### 🛠️ How It Works

1. Consider only activities where `activity = 'login'`.
2. Find the earliest login date for each user using `MIN()`.
3. Keep first-login dates within the last 90 days.
4. Group users by their first login date.
5. Count the users for each date.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans the Traffic table to find first logins)*

**Space Complexity:** `O(u)` *(stores the first login date for each unique user)*
