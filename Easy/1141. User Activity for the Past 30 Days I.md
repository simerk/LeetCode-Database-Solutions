## 🚀 1141. User Activity for the Past 30 Days I

### 📖 Problem

Write a solution to find the daily active user count for a period of `30` days ending `2019-07-27` inclusively. A user was active on someday if they made at least one activity on that day.

Return the result table in **any order**.

Note: **Any** activity from (`'open_session'`, `'end_session'`, `'scroll_down'`, `'send_message'`) will be considered valid activity for a user to be considered active on a day.

---

### 📝 Example
```text
Input: 
Activity table:
+---------+------------+---------------+---------------+
| user_id | session_id | activity_date | activity_type |
+---------+------------+---------------+---------------+
| 1       | 1          | 2019-07-20    | open_session  |
| 1       | 1          | 2019-07-20    | scroll_down   |
| 1       | 1          | 2019-07-20    | end_session   |
| 2       | 4          | 2019-07-20    | open_session  |
| 2       | 4          | 2019-07-21    | send_message  |
| 2       | 4          | 2019-07-21    | end_session   |
| 3       | 2          | 2019-07-21    | open_session  |
| 3       | 2          | 2019-07-21    | send_message  |
| 3       | 2          | 2019-07-21    | end_session   |
| 4       | 3          | 2019-06-25    | open_session  |
| 4       | 3          | 2019-06-25    | end_session   |
+---------+------------+---------------+---------------+
Output: 
+------------+--------------+ 
| day        | active_users |
+------------+--------------+ 
| 2019-07-20 | 2            |
| 2019-07-21 | 2            |
+------------+--------------+ 
Explanation: Note that we do not care about days with zero active users.
```
---


### 💡 Idea

The goal is to report the **number of active users for each day** during the 30-day period ending on **2019-07-27**.

A user is considered **active** if they performed at least one activity on that day. Therefore, for each date, we count the number of **distinct users** who were active.

---

### 💻 Solution

```sql
SELECT activity_date AS day, COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'
GROUP BY activity_date;
```

---

### 🛠️ How It Works

1. Filter the records to include only activities between **2019-06-28** and **2019-07-27**.
2. Group the records by `activity_date`.
3. Count the number of **distinct** `user_id`s for each day.
4. Return the activity date as `day` and the corresponding number of active users.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(single scan with filtering and grouping)*

**Space Complexity:** `O(n)` *(stores grouped activity dates)*
