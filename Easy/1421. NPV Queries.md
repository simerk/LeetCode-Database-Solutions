## 🚀 1421. NPV Queries 🔒

### 📖 Problem

Write a solution to find the `npv` of each query of the `Queries` table.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
NPV table:                      Queries table:
+------+--------+--------+      +------+--------+
| id   | year   | npv    |      | id   | year   |
+------+--------+--------+      +------+--------+
| 1    | 2018   | 100    |      | 1    | 2019   |
| 7    | 2020   | 30     |      | 2    | 2008   |
| 13   | 2019   | 40     |      | 3    | 2009   |
| 1    | 2019   | 113    |      | 7    | 2018   |
| 2    | 2008   | 121    |      | 7    | 2019   |
| 3    | 2009   | 12     |      | 7    | 2020   |
| 11   | 2020   | 99     |      | 13   | 2019   |
| 7    | 2019   | 0      |      +------+--------+
+------+--------+--------+
Output: 
+------+--------+--------+
| id   | year   | npv    |
+------+--------+--------+
| 1    | 2019   | 113    |
| 2    | 2008   | 121    |
| 3    | 2009   | 12     |
| 7    | 2018   | 0      |
| 7    | 2019   | 0      |
| 7    | 2020   | 30     |
| 13   | 2019   | 40     |
+------+--------+--------+
Explanation: 
The npv value of (7, 2018) is not present in the NPV table, we consider it 0.
The npv values of all other queries can be found in the NPV table.
```
---

### 💡 Idea

Use a `LEFT JOIN` from `Queries` to `NPV` on both `id` and `year`. If a matching NPV record does not exist, use `COALESCE()` to return `0`.

---

### 💻 Solution

```sql
SELECT q.id, q.year,
COALESCE(n.npv, 0) AS npv
FROM Queries q
LEFT JOIN NPV n
ON q.id = n.id AND q.year = n.year;
```

---

### 🛠️ How It Works

1. Start with every query from `Queries`.
2. Match each query with `NPV` using both `id` and `year`.
3. If a matching record exists, return its `npv`.
4. If no match exists, `COALESCE()` changes `NULL` to `0`.
5. `LEFT JOIN` ensures every query appears in the result.

---

### ⏱️ Complexity

**Time Complexity:** `O(Q + N)` *(joins the queries with the NPV records)*

**Space Complexity:** `O(Q)` *(stores the resulting query records)*
