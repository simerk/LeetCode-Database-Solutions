## 🚀 1757. Recyclable and Low Fat Products

### 📖 Problem

Write a solution to find the ids of products that are both low fat and recyclable.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Products table:
+-------------+----------+------------+
| product_id  | low_fats | recyclable |
+-------------+----------+------------+
| 0           | Y        | N          |
| 1           | Y        | Y          |
| 2           | N        | Y          |
| 3           | Y        | Y          |
| 4           | N        | N          |
+-------------+----------+------------+
Output: 
+-------------+
| product_id  |
+-------------+
| 1           |
| 3           |
+-------------+
Explanation: Only products 1 and 3 are both low fat and recyclable.
```
---

### 💡 Idea

The goal is to find the IDs of products that are:

- **Low fat** (`low_fats = 'Y'`)
- **Recyclable** (`recyclable = 'Y'`)

We simply filter the `Products` table using both conditions.

---

## 💻 Solution

```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

---

### 🛠️ How It Works

1. Read the records from the `Products` table.
2. Filter products where:
   - `low_fats = 'Y'`
   - `recyclable = 'Y'`
3. Return the corresponding `product_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(single scan of the table)*

**Space Complexity:** `O(1)`
