## 🚀 1407. Top Travellers

### 📖 Problem

Write a solution to report the distance traveled by each user.

Return the result table ordered by `travelled_distance` in **descending order**, if two or more users traveled the same distance, order them by their `name` in **ascending order**.

---

### 📝 Example
```text
Input: 
Rides table:                           Users table:
+------+----------+----------+         +------+-----------+
| id   | user_id  | distance |         | id   | name      |
+------+----------+----------+         +------+-----------+
| 1    | 1        | 120      |         | 1    | Alice     |
| 2    | 2        | 317      |         | 2    | Bob       |
| 3    | 3        | 222      |         | 3    | Alex      |
| 4    | 7        | 100      |         | 4    | Donald    |
| 5    | 13       | 312      |         | 7    | Lee       |
| 6    | 19       | 50       |         | 13   | Jonathan  |
| 7    | 7        | 120      |         | 19   | Elvis     |
| 8    | 19       | 400      |         +------+-----------+
| 9    | 7        | 230      |
+------+----------+----------+
Output: 
+----------+--------------------+
| name     | travelled_distance |
+----------+--------------------+
| Elvis    | 450                |
| Lee      | 450                |
| Bob      | 317                |
| Jonathan | 312                |
| Alex     | 222                |
| Alice    | 120                |
| Donald   | 0                  |
+----------+--------------------+
Explanation: 
Elvis and Lee traveled 450 miles, Elvis is the top traveler as his name is alphabetically smaller than Lee.
Bob, Jonathan, Alex, and Alice have only one ride and we just order them by the total distances of the ride.
Donald did not have any rides, the distance traveled by him is 0.
```
---

### 💡 Idea

The goal is to calculate the total distance traveled by each user.

Since some users may not have any rides, we use a **LEFT JOIN** to include all users. We then sum the distances of their rides and replace `NULL` values with `0` for users who haven't traveled.

Finally, the results are sorted by:
- Total traveled distance in **descending** order.
- User name in **ascending** order to break ties.

---

## 💻 Solution

```sql
SELECT u.name, IFNULL(SUM(r.distance), 0) AS travelled_distance
FROM Users u
LEFT JOIN Rides r
ON u.id = r.user_id
GROUP BY u.id, u.name
ORDER BY travelled_distance DESC, u.name;
```

---

### 🛠️ How It Works

1. Start with the `Users` table so every user is included.
2. `LEFT JOIN` the `Rides` table using `user_id`.
3. Sum the `distance` of all rides for each user.
4. Use `IFNULL()` to replace `NULL` with `0` for users who have no rides.
5. Group the results by user.
6. Sort by:
   - Total traveled distance (descending).
   - User name (ascending).

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(single join followed by grouping)*

**Space Complexity:** `O(n)` *(stores grouped users)*
