## 🚀 603. Consecutive Available Seats 🔒

### 📖 Problem

Find all the consecutive available seats in the cinema.

Return the result table **ordered** by `seat_id` in **ascending** order.

The test cases are generated so that more than two seats are consecutively available.

---

### 📝 Example

```text
Input: 
Cinema table:
+---------+------+
| seat_id | free |
+---------+------+
| 1       | 1    |
| 2       | 0    |
| 3       | 1    |
| 4       | 1    |
| 5       | 1    |
+---------+------+
Output: 
+---------+
| seat_id |
+---------+
| 3       |
| 4       |
| 5       |
+---------+
```
---

### 💡 Idea

We need to find seats that are **available (`free = 1`)** and have another available seat immediately before or after them.

We can use `LAG()` and `LEAD()` to check the neighboring seats.

---

### 💻 Solution

```sql
SELECT seat_id
FROM (
    SELECT seat_id, free,
    LAG(free) OVER (ORDER BY seat_id) AS prev_free,
    LEAD(free) OVER (ORDER BY seat_id) AS next_free
    FROM Cinema
) AS seats
WHERE free = 1 AND (prev_free = 1 OR next_free = 1)
ORDER BY seat_id;
```

---

### 🛠️ How It Works

1. Use `LAG()` to check whether the previous seat is available.
2. Use `LEAD()` to check whether the next seat is available.
3. Keep only seats where `free = 1`.
4. A seat qualifies if either its previous or next seat is also available.
5. Sort the result by `seat_id` in ascending order.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting by `seat_id` for the window functions)*

**Space Complexity:** `O(n)` *(stores the window function results)*
