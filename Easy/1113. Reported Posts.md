## 🚀 1113. Reported Posts 🔒

### 📖 Problem

Write a solution to report the number of posts reported yesterday for each report reason. Assume today is `2019-07-05`.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Actions table:
+---------+---------+-------------+--------+--------+
| user_id | post_id | action_date | action | extra  |
+---------+---------+-------------+--------+--------+
| 1       | 1       | 2019-07-01  | view   | null   |
| 1       | 1       | 2019-07-01  | like   | null   |
| 1       | 1       | 2019-07-01  | share  | null   |
| 2       | 4       | 2019-07-04  | view   | null   |
| 2       | 4       | 2019-07-04  | report | spam   |
| 3       | 4       | 2019-07-04  | view   | null   |
| 3       | 4       | 2019-07-04  | report | spam   |
| 4       | 3       | 2019-07-02  | view   | null   |
| 4       | 3       | 2019-07-02  | report | spam   |
| 5       | 2       | 2019-07-04  | view   | null   |
| 5       | 2       | 2019-07-04  | report | racism |
| 5       | 5       | 2019-07-04  | view   | null   |
| 5       | 5       | 2019-07-04  | report | racism |
+---------+---------+-------------+--------+--------+
Output: 
+---------------+--------------+
| report_reason | report_count |
+---------------+--------------+
| spam          | 1            |
| racism        | 2            |
+---------------+--------------+
Explanation: Note that we only care about report reasons with non-zero number of reports.
```
---

### 💡 Idea

We need to count the number of posts reported **yesterday**, grouped by the report reason.

Since the same post can be reported multiple times for the same reason, we should count **distinct `post_id`** for each `extra` reason.

---

### 💻 Solution

```sql
SELECT
extra AS report_reason,
COUNT(DISTINCT post_id) AS report_count
FROM Actions
WHERE action = 'report' AND action_date = '2019-07-04'
GROUP BY extra;
```

---

### 🛠️ How It Works

1. Filter only `report` actions.
2. Keep reports from yesterday, `2019-07-04`.
3. Group reports by their reason stored in `extra`.
4. Count distinct posts for each reason.
5. Return only reasons that have reports.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans the Actions table to filter and group reports)*

**Space Complexity:** `O(k)` *(stores counts for each unique report reason)*
