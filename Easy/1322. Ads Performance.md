## 🚀 1322. Ads Performance 🔒

### 📖 Problem

A company is running Ads and wants to calculate the performance of each Ad.

Performance of the Ad is measured using Click-Through Rate (CTR) where:

Write a solution to find the `ctr` of each Ad. **Round** `ctr` to **two decimal points**.

Return the result table ordered by `ctr` in **descending** order and by `ad_id` in **ascending** order in case of a tie.

---

### 📝 Example
```text
Input: 
Ads table:
+-------+---------+---------+
| ad_id | user_id | action  |
+-------+---------+---------+
| 1     | 1       | Clicked |
| 2     | 2       | Clicked |
| 3     | 3       | Viewed  |
| 5     | 5       | Ignored |
| 1     | 7       | Ignored |
| 2     | 7       | Viewed  |
| 3     | 5       | Clicked |
| 1     | 4       | Viewed  |
| 2     | 11      | Viewed  |
| 1     | 2       | Clicked |
+-------+---------+---------+
Output: 
+-------+-------+
| ad_id | ctr   |
+-------+-------+
| 1     | 66.67 |
| 3     | 50.00 |
| 2     | 33.33 |
| 5     | 0.00  |
+-------+-------+
Explanation: 
for ad_id = 1, ctr = (2/(2+1)) * 100 = 66.67
for ad_id = 2, ctr = (1/(1+2)) * 100 = 33.33
for ad_id = 3, ctr = (1/(1+1)) * 100 = 50.00
for ad_id = 5, ctr = 0.00, Note that ad_id = 5 has no clicks or views.
Note that we do not care about Ignored Ads.
```
---

### 💡 Idea

Calculate the **Click-Through Rate (CTR)** for each ad using the number of clicks divided by the total number of clicks and views. Ignored actions are excluded. Ads with no clicks or views should have a CTR of `0.00`.

---

### 💻 Solution

```sql
SELECT
    ad_id,
    ROUND(
        100.0 * SUM(action = 'Clicked') /
        NULLIF(SUM(action IN ('Clicked', 'Viewed')), 0),
        2) AS ctr
FROM Ads
GROUP BY ad_id
ORDER BY ctr DESC, ad_id ASC;
```

---

### 🛠️ How It Works

1. Group all records by `ad_id`.
2. Count clicks using `SUM(action = 'Clicked')`.
3. Count both clicks and views for the denominator.
4. Ignore `Ignored` actions.
5. Use `NULLIF()` to avoid division by zero for ads with no clicks or views.
6. `ROUND()` formats the CTR to two decimal places.
7. Sort by CTR descending, then `ad_id` ascending for ties.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans all ad records and groups them by `ad_id`)*

**Space Complexity:** `O(a)` *(stores one aggregate result per ad)*
