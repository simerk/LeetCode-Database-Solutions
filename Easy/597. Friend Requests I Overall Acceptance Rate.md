## 🚀 597. Friend Requests I Overall Acceptance Rate 🔒

### 📖 Problem

Find the overall acceptance rate of requests, which is the number of acceptance divided by the number of requests. Return the answer rounded to 2 decimals places.

**Note that:**

- The accepted requests are not necessarily from the table `friend_request`. In this case, Count the total accepted requests (no matter whether they are in the original requests), and divide it by the number of requests to get the acceptance rate.
- It is possible that a sender sends multiple requests to the same receiver, and a request could be accepted more than once. In this case, the ‘duplicated’ requests or acceptances are only counted once.
- If there are no requests at all, you should return 0.00 as the `accept_rate`.

---

### 📝 Example

```text
Input: 
FriendRequest table:
+-----------+------------+--------------+
| sender_id | send_to_id | request_date |
+-----------+------------+--------------+
| 1         | 2          | 2016/06/01   |
| 1         | 3          | 2016/06/01   |
| 1         | 4          | 2016/06/01   |
| 2         | 3          | 2016/06/02   |
| 3         | 4          | 2016/06/09   |
+-----------+------------+--------------+
RequestAccepted table:
+--------------+-------------+-------------+
| requester_id | accepter_id | accept_date |
+--------------+-------------+-------------+
| 1            | 2           | 2016/06/03  |
| 1            | 3           | 2016/06/08  |
| 2            | 3           | 2016/06/08  |
| 3            | 4           | 2016/06/09  |
| 3            | 4           | 2016/06/10  |
+--------------+-------------+-------------+
Output: 
+-------------+
| accept_rate |
+-------------+
| 0.8         |
+-------------+
Explanation: 
There are 4 unique accepted requests, and there are 5 requests in total. So the rate is 0.80.
```
---

### 💡 Idea

We need to calculate the overall acceptance rate using **unique requests** and **unique accepted requests**.

Use `COUNT(DISTINCT ...)` on the sender-receiver pairs to remove duplicate requests and acceptances. `COALESCE` ensures the result is `0.00` when there are no requests.

---

### 💻 Solution

```sql
SELECT ROUND(
    COALESCE(
        (SELECT COUNT(DISTINCT requester_id, accepter_id)
         FROM RequestAccepted) /
        NULLIF(
            (SELECT COUNT(DISTINCT sender_id, send_to_id)
             FROM FriendRequest), 0),
        0),
    2) AS accept_rate;
```

---

### 🛠️ How It Works

1. Count unique sender-receiver pairs from `FriendRequest`.
2. Count unique requester-accepter pairs from `RequestAccepted`.
3. Divide accepted requests by total requests.
4. `NULLIF` prevents division by zero.
5. `COALESCE` returns `0` when there are no requests.
6. Round the acceptance rate to 2 decimal places.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(scans both tables to count distinct pairs)*

**Space Complexity:** `O(n + m)` *(stores distinct pairs during aggregation)*
