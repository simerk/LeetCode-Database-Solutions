## 🚀 1076. Project Employees II 🔒

### 📖 Problem

Write a solution to report all the **projects** that have the most employees.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Project table:                         Employee table:
+-------------+-------------+          +-------------+--------+------------------+
| project_id  | employee_id |          | employee_id | name   | experience_years |
+-------------+-------------+          +-------------+--------+------------------+
| 1           | 1           |          | 1           | Khaled | 3                |
| 1           | 2           |          | 2           | Ali    | 2                |
| 1           | 3           |          | 3           | John   | 1                |
| 2           | 1           |          | 4           | Doe    | 2                |
| 2           | 4           |          +-------------+--------+------------------+
+-------------+-------------+
Output: 
+-------------+
| project_id  |
+-------------+
| 1           |
+-------------+
Explanation: The first project has 3 employees while the second one has 2.
```
---

### 💡 Idea

We need to find the **projects with the highest number of employees**.

First, count the employees in each project. Then find the maximum employee count and return all projects having that count.

---

### 💻 Solution

```sql
WITH project_counts AS (
    SELECT project_id, COUNT(employee_id) AS employee_count
    FROM Project
    GROUP BY project_id)
SELECT project_id FROM project_counts
WHERE employee_count = (
    SELECT MAX(employee_count)
    FROM project_counts);
```

---

### 🛠️ How It Works

1. Group the `Project` table by `project_id`.
2. Count the employees in each project.
3. Find the maximum employee count.
4. Return every project whose employee count equals the maximum.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans and groups the project records)*

**Space Complexity:** `O(k)` *(stores the employee count for each unique project)*
