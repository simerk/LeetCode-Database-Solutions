## 🚀 3570. Find Books with No Available Copies

### 💡 Idea

The goal is to find books that have **no available copies** in the library.

A book has zero available copies when:

- It has one or more borrowing records where `return_date IS NULL` (currently borrowed).
- The number of currently borrowed copies is equal to the book's `total_copies`.

We join the two tables, count the number of currently borrowed copies for each book, and keep only those books where all copies are currently borrowed.

---

## 💻 Solution

```sql
SELECT lb.book_id, lb.title, lb.author, lb.genre, lb.publication_year,
COUNT(br.record_id) AS current_borrowers
FROM library_books lb
JOIN borrowing_records br ON lb.book_id = br.book_id
WHERE br.return_date IS NULL
GROUP BY lb.book_id, lb.title, lb.author, lb.genre, lb.publication_year, lb.total_copies
HAVING COUNT(br.record_id) = lb.total_copies
ORDER BY current_borrowers DESC, title;
```

---

### 🛠️ How It Works

1. Join the `library_books` and `borrowing_records` tables using `book_id`.
2. Keep only the books that are **currently borrowed** using `return_date IS NULL`.
3. Group the records by each book.
4. Count the number of current borrowers using `COUNT(br.record_id)`.
5. Use `HAVING` to keep only books where the current borrowers equal the total number of copies.
6. Sort the result by current borrowers (descending) and book title (ascending).

---

### ⏱️ Complexity

**Time Complexity:** `O(n)`

- `n` = number of borrowing records.

**Space Complexity:** `O(n)`

- Used for grouping the borrowing records by book.
