## 🚀 1294. Weather Type in Each Country 🔒

### 📖 Problem

Write a solution to find the type of weather in each country for **November 2019**.

The type of weather is:

- Cold if the average `weather_state` is less than or equal `15`,
- Hot if the average `weather_state` is greater than or equal to `25`, and
- **Warm** otherwise.

Return the result table in **any order**.

---

---

### 💡 Idea

Filter the weather data to **November 2019**, calculate the average `weather_state` for each country, and classify the average as Cold, Hot, or Warm using `CASE`.

---

### 💻 Solution

```sql
SELECT c.country_name,
CASE WHEN AVG(w.weather_state) <= 15 THEN 'Cold'
WHEN AVG(w.weather_state) >= 25 THEN 'Hot'
ELSE 'Warm' END AS weather_type
FROM Countries c
JOIN Weather w ON c.country_id = w.country_id
WHERE w.day BETWEEN '2019-11-01' AND '2019-11-30'
GROUP BY c.country_id, c.country_name;
```

---

### 🛠️ How It Works

1. Join `Countries` with `Weather` using `country_id`.
2. Filter weather records to November 2019.
3. Calculate the average `weather_state` for each country.
4. Use `CASE` to classify the average as Cold, Hot, or Warm.
5. Countries with no November weather records are excluded by the `JOIN`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(processes the filtered weather records)*

**Space Complexity:** `O(c)` *(stores groups for each country)*
