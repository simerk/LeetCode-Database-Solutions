## 🚀 3465. Find Products with Valid Serial Numbers

### 📖 Problem

Write a solution to find all products whose description contains a **valid serial number** pattern. A valid serial number follows these rules:

- It starts with the letters **SN** (case-sensitive).
- Followed by exactly `4` digits.
- It must have a hyphen (-) **followed by exactly** `4` digits.
- The serial number must be within the description (it may not necessarily start at the beginning).

Return the result table ordered by `product_id` in **ascending** order.

---

### 📝 Example
```text
Input:
products table:
+------------+--------------+------------------------------------------------------+
| product_id | product_name | description                                          |
+------------+--------------+------------------------------------------------------+
| 1          | Widget A     | This is a sample product with SN1234-5678            |
| 2          | Widget B     | A product with serial SN9876-1234 in the description |
| 3          | Widget C     | Product SN1234-56789 is available now                |
| 4          | Widget D     | No serial number here                                |
| 5          | Widget E     | Check out SN4321-8765 in this description            |
+------------+--------------+------------------------------------------------------+
Output:
+------------+--------------+------------------------------------------------------+
| product_id | product_name | description                                          |
+------------+--------------+------------------------------------------------------+
| 1          | Widget A     | This is a sample product with SN1234-5678            |
| 2          | Widget B     | A product with serial SN9876-1234 in the description |
| 5          | Widget E     | Check out SN4321-8765 in this description            |
+------------+--------------+------------------------------------------------------+
Explanation:
• Product 1: Valid serial number SN1234-5678
• Product 2: Valid serial number SN9876-1234
• Product 3: Invalid serial number SN1234-56789 (contains 5 digits after the hyphen)
• Product 4: No serial number in the description
• Product 5: Valid serial number SN4321-8765
The result table is ordered by product_id in ascending order.
```
---

### 💡 Idea

The goal is to find all products whose **description** contains a valid serial number.

A valid serial number must:

- Start with **`SN`** (case-sensitive).
- Be followed by **exactly 4 digits**.
- Contain a **hyphen (`-`)**.
- End with **exactly 4 digits**.
- Appear anywhere within the description.

We use the `REGEXP_LIKE()` function along with **word boundaries (`\b`)** to search for the required pattern.

---

## 💻 Solution

```sql
SELECT *
FROM Products
WHERE REGEXP_LIKE (description, '\\bSN[0-9]{4}-[0-9]{4}\\b', 'c')
ORDER BY product_id;
```

---

### 🛠️ How It Works

1. Use `REGEXP_LIKE()` to search the `description` for a valid serial number.

2. The regular expression used is:

   ```regex
   \bSN[0-9]{4}-[0-9]{4}\b
   ```

3. `\b`

   Represents a **word boundary**.

   It ensures the serial number starts at the beginning of a word and is not part of another word.

   **Example:**

   ```
   Product SN1234-5678     ✅
   ABCSN1234-5678          ❌
   ```

4. `SN`

   Matches the uppercase letters **`SN`** exactly.

5. `[0-9]{4}`

   - `[0-9]` → Matches any digit from `0` to `9`.
   - `{4}` → Means **exactly 4 digits**.

   Examples:

   ```
   1234
   0001
   9876
   ```

6. `-`

   Matches the literal hyphen between the two groups of digits.

7. `[0-9]{4}`

   Again matches **exactly 4 digits** after the hyphen.

8. `\b`

   Another **word boundary**.

   It ensures the serial number ends at the end of a word.

   **Example:**

   ```
   SN1234-5678      ✅
   SN1234-56789     ❌
   SN1234-5678ABC   ❌
   ```

9. The third argument `'c'`

   ```sql
   REGEXP_LIKE(description, pattern, 'c')
   ```

   enables **case-sensitive matching**, so only uppercase `SN` is accepted.

10. Return all matching products ordered by `product_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n × m)`

- `n` = number of rows
- `m` = average length of the description

**Space Complexity:** `O(1)`
