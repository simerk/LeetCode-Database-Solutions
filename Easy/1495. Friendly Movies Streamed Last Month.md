## 🚀 1495. Friendly Movies Streamed Last Month 🔒

### 📖 Problem

Write a solution to report the distinct titles of the kid-friendly movies streamed in June 2020.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
TVProgram table:                                       Content table:
+--------------------+--------------+-------------+    +------------+----------------+---------------+---------------+
| program_date       | content_id   | channel     |    | content_id | title          | Kids_content  | content_type  |
+--------------------+--------------+-------------+    +------------+----------------+---------------+---------------+
| 2020-06-10 08:00   | 1            | LC-Channel  |    | 1          | Leetcode Movie | N             | Movies        |
| 2020-05-11 12:00   | 2            | LC-Channel  |    | 2          | Alg. for Kids  | Y             | Series        |
| 2020-05-12 12:00   | 3            | LC-Channel  |    | 3          | Database Sols  | N             | Series        |
| 2020-05-13 14:00   | 4            | Disney Ch   |    | 4          | Aladdin        | Y             | Movies        |
| 2020-06-18 14:00   | 4            | Disney Ch   |    | 5          | Cinderella     | Y             | Movies        |
| 2020-07-15 16:00   | 5            | Disney Ch   |    +------------+----------------+---------------+---------------+
+--------------------+--------------+-------------+
Output: 
+--------------+
| title        |
+--------------+
| Aladdin      |
+--------------+
Explanation: 
"Leetcode Movie" is not a content for kids.
"Alg. for Kids" is not a movie.
"Database Sols" is not a movie
"Alladin" is a movie, content for kids and was streamed in June 2020.
"Cinderella" was not streamed in June 2020.
```
---

### 💡 Idea

Join `TVProgram` with `Content` and filter for **kid-friendly movies** that were streamed during June 2020. Use `DISTINCT` because the same movie can be streamed multiple times.

---

### 💻 Solution

```sql
SELECT DISTINCT c.title FROM TVProgram t
JOIN Content c ON t.content_id = c.content_id
WHERE c.Kids_content = 'Y'
  AND c.content_type = 'Movies'
  AND t.program_date >= '2020-06-01'
  AND t.program_date < '2020-07-01';
```

---

### 🛠️ How It Works

1. Join `TVProgram` with `Content` using `content_id`.
2. Keep only content marked as kid-friendly.
3. Filter for movies only.
4. Restrict `program_date` to June 2020.
5. Use `DISTINCT` to return each movie title only once.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(each program record is evaluated against the filters)*

**Space Complexity:** `O(k)` *(stores the distinct movie titles in the result)*
