## 🚀 1789. Primary Department for Each Employee

### 📖 Problem

Employees can belong to multiple departments. When the employee joins other departments, they need to decide which department is their primary department. Note that when an employee belongs to only one department, their primary column is `'N'`.

Write a solution to report all the employees with their primary department. For employees who belong to one department, report their only department.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Employee table:
+-------------+---------------+--------------+
| employee_id | department_id | primary_flag |
+-------------+---------------+--------------+
| 1           | 1             | N            |
| 2           | 1             | Y            |
| 2           | 2             | N            |
| 3           | 3             | N            |
| 4           | 2             | N            |
| 4           | 3             | Y            |
| 4           | 4             | N            |
+-------------+---------------+--------------+
Output: 
+-------------+---------------+
| employee_id | department_id |
+-------------+---------------+
| 1           | 1             |
| 2           | 1             |
| 3           | 3             |
| 4           | 3             |
+-------------+---------------+
Explanation: 
- The Primary department for employee 1 is 1.
- The Primary department for employee 2 is 1.
- The Primary department for employee 3 is 3.
- The Primary department for employee 4 is 3.
```
---

### 💡 Idea

The goal is to determine the **primary department** for each employee.

- If an employee belongs to **only one department**, that department is considered the primary department.
- If an employee belongs to **multiple departments**, the row where `primary_flag = 'Y'` represents the primary department.

We can identify both cases by grouping employees and using a `HAVING` clause.

---

## 💻 Solution

```sql
SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y'
UNION
SELECT employee_id, department_id
FROM Employee
GROUP BY employee_id
HAVING COUNT(*) = 1;
```

---

### 🛠️ How It Works

1. Select employees whose `primary_flag = 'Y'`.
2. Select employees who belong to only one department using:
   - `GROUP BY employee_id`
   - `HAVING COUNT(*) = 1`
3. Combine both result sets using `UNION`.
4. Since `UNION` removes duplicates, employees appearing in both queries are returned only once.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(two scans of the table)*

**Space Complexity:** `O(n)` *(stores the union result)*
