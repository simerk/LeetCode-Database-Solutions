## 🚀 1777. Product's Price for Each Store 🔒

### 📖 Problem

Find the price of each product in each store.

Return the result table in **any order**.



---

### 📝 Example

```text
Input: 
Products table:
+-------------+--------+-------+
| product_id  | store  | price |
+-------------+--------+-------+
| 0           | store1 | 95    |
| 0           | store3 | 105   |
| 0           | store2 | 100   |
| 1           | store1 | 70    |
| 1           | store3 | 80    |
+-------------+--------+-------+
Output: 
+-------------+--------+--------+--------+
| product_id  | store1 | store2 | store3 |
+-------------+--------+--------+--------+
| 0           | 95     | 100    | 105    |
| 1           | 70     | null   | 80     |
+-------------+--------+--------+--------+
Explanation: 
Product 0 price's are 95 for store1, 100 for store2 and, 105 for store3.
Product 1 price's are 70 for store1, 80 for store3 and, it's not sold in store2.
```
---

### 💡 Idea

The data is stored in rows, but the required output has one row per product with each store as a separate column.

Use conditional aggregation with `MAX()` to pivot the store prices into columns.

---

### 💻 Solution

```sql
SELECT
    product_id,
    MAX(CASE WHEN store = 'store1' THEN price END) AS store1,
    MAX(CASE WHEN store = 'store2' THEN price END) AS store2,
    MAX(CASE WHEN store = 'store3' THEN price END) AS store3
FROM Products
GROUP BY product_id;
```

---

### 🛠️ How It Works

1. Group the rows by `product_id`.
2. `CASE` selects the price for each specific store.
3. `MAX()` combines the selected price into its corresponding store column.
4. If a product is not sold in a store, the `CASE` returns `NULL`.
5. The result contains one row for each product.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans all product records)*

**Space Complexity:** `O(k)` *(stores the grouped product results)*
