## 🚀 1082. Sales Analysis I 🔒

### 📖 Problem

Write a solution that reports the best **seller** by total sales price, If there is a tie, report them all.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Product table:                                   Sales table:
+------------+--------------+------------+       +-----------+------------+----------+------------+----------+-------+
| product_id | product_name | unit_price |       | seller_id | product_id | buyer_id | sale_date  | quantity | price |
+------------+--------------+------------+       +-----------+------------+----------+------------+----------+-------+
| 1          | S8           | 1000       |       | 1         | 1          | 1        | 2019-01-21 | 2        | 2000  |
| 2          | G4           | 800        |       | 1         | 2          | 2        | 2019-02-17 | 1        | 800   |
| 3          | iPhone       | 1400       |       | 2         | 2          | 3        | 2019-06-02 | 1        | 800   |
+------------+--------------+------------+       | 3         | 3          | 4        | 2019-05-13 | 2        | 2800  |
                                                 +-----------+------------+----------+------------+----------+-------+
Output: 
+-------------+
| seller_id   |
+-------------+
| 1           |
| 3           |
+-------------+
Explanation: Both sellers with id 1 and 3 sold products with the most total price of 2800.
```
---

### 💡 Idea

We need to find the **seller(s) with the highest total sales price**.

First, calculate the total sales price for each seller using `SUM()`. Then find the maximum total and return all sellers whose total sales equals that maximum.

---

### 💻 Solution

```sql id="m2k7qa"
WITH seller_sales AS (
    SELECT seller_id, SUM(price) AS total_sales
    FROM Sales
    GROUP BY seller_id)
SELECT seller_id
FROM seller_sales
WHERE total_sales = (
    SELECT MAX(total_sales)
    FROM seller_sales);
```

---

### 🛠️ How It Works

1. Group the `Sales` table by `seller_id`.
2. Calculate each seller's total sales using `SUM(price)`.
3. Find the highest total sales using `MAX()`.
4. Return all sellers whose total sales equals the maximum.
5. This includes all sellers in case of a tie.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(scans and groups the sales records)*

**Space Complexity:** `O(k)` *(stores one total sales value for each unique seller)*
