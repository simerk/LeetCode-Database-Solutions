## 🚀 1633. Percentage of Users Attended a Contest

### 📖 Problem

Write a solution to find the percentage of the users registered in each contest rounded to **two decimals**.

Return the result table ordered by `percentage` in **descending order**. In case of a tie, order it by `contest_id` in **ascending order**.

---

### 📝 Example
```text
Input: 
Register table:                     Users table:
+------------+---------+            +---------+-----------+
| contest_id | user_id |            | user_id | user_name |
+------------+---------+            +---------+-----------+
| 215        | 6       |            | 6       | Alice     |
| 209        | 2       |            | 2       | Bob       |
| 208        | 2       |            | 7       | Alex      |
| 210        | 6       |            +---------+-----------+
| 208        | 6       |
| 209        | 7       |
| 209        | 6       |
| 215        | 7       |
| 208        | 7       |
| 210        | 2       |
| 207        | 2       |
| 210        | 7       |
+------------+---------+
Output: 
+------------+------------+
| contest_id | percentage |
+------------+------------+
| 208        | 100.0      |
| 209        | 100.0      |
| 210        | 100.0      |
| 215        | 66.67      |
| 207        | 33.33      |
+------------+------------+
Explanation: 
All the users registered in contests 208, 209, and 210. The percentage is 100% and we sort them in the answer table by contest_id in ascending order.
Alice and Alex registered in contest 215 and the percentage is ((2/3) * 100) = 66.67%
Bob registered in contest 207 and the percentage is ((1/3) * 100) = 33.33%
```
---

### 💡 Idea

The goal is to calculate the percentage of all users who registered for each contest.

For each `contest_id`:

- Count the number of registered users.
- Divide it by the total number of users.
- Multiply by **100** to obtain the percentage.
- Round the result to **2 decimal places**.

Finally, sort the results by percentage in descending order and by `contest_id` in ascending order to break ties.

---

## 💻 Solution

```sql
SELECT contest_id,
    ROUND(
        COUNT(user_id) * 100 /
        (SELECT COUNT(*) FROM Users),
        2) AS percentage
FROM Register
GROUP BY contest_id
ORDER BY percentage DESC, contest_id;
```

---

### 🛠️ How It Works

1. Group the `Register` table by `contest_id`.
2. Count the number of registered users for each contest using `COUNT(user_id)`.
3. Use a subquery to calculate the total number of users.
4. Divide the number of registered users by the total users and multiply by **100**.
5. Round the percentage to **2 decimal places**.
6. Sort by:
   - Percentage (descending).
   - Contest ID (ascending).

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(single scan of `Register`; the scalar subquery for total users is evaluated once)*

**Space Complexity:** `O(n)` *(stores grouped contests)*
