## 🚀 1853. Convert Date Format 🔒

### 📖 Problem

Write a solution to convert each date in `Days` into a string formatted as `"day_name, month_name day, year"`.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Days table:
+------------+
| day        |
+------------+
| 2022-04-12 |
| 2021-08-09 |
| 2020-06-26 |
+------------+
Output: 
+-------------------------+
| day                     |
+-------------------------+
| Tuesday, April 12, 2022 |
| Monday, August 9, 2021  |
| Friday, June 26, 2020   |
+-------------------------+
Explanation: Please note that the output is case-sensitive.
```
---

### 💡 Idea

Use MySQL's `DATE_FORMAT()` function to format the date into the required weekday, month, day, and year structure.

* `%W` → full weekday name
* `%M` → full month name
* `%e` → day of the month without leading zero
* `%Y` → four-digit year

---

### 💻 Solution

```sql
SELECT DATE_FORMAT(day, '%W, %M %e, %Y') AS day
FROM Days;
```

---

### 🛠️ How It Works

1. `%W` converts the date to the full weekday name.
2. `%M` converts the date to the full month name.
3. `%e` returns the day without a leading zero.
4. `%Y` returns the four-digit year.
5. `DATE_FORMAT()` combines them into the required format.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(formats each date once)*

**Space Complexity:** `O(1)` *(no additional data structures are required)*
