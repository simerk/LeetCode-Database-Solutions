## 🚀 1607. Sellers With No Sales 🔒

### 📖 Problem

Write a solution to report the names of all sellers who did not make any sales in `2020`.

Return the result table ordered by `seller_name` in **ascending** order.

---

### 📝 Example

```text
Input: 
Customer table:                     Seller table:
+--------------+---------------+    +-------------+-------------+
| customer_id  | customer_name |    | seller_id   | seller_name |
+--------------+---------------+    +-------------+-------------+
| 101          | Alice         |    | 1           | Daniel      |
| 102          | Bob           |    | 2           | Elizabeth   |
| 103          | Charlie       |    | 3           | Frank       |
+--------------+---------------+    +-------------+-------------+
Orders table:
+-------------+------------+--------------+-------------+-------------+
| order_id    | sale_date  | order_cost   | customer_id | seller_id   |
+-------------+------------+--------------+-------------+-------------+
| 1           | 2020-03-01 | 1500         | 101         | 1           |
| 2           | 2020-05-25 | 2400         | 102         | 2           |
| 3           | 2019-05-25 | 800          | 101         | 3           |
| 4           | 2020-09-13 | 1000         | 103         | 2           |
| 5           | 2019-02-11 | 700          | 101         | 2           |
+-------------+------------+--------------+-------------+-------------+
Output: 
+-------------+
| seller_name |
+-------------+
| Frank       |
+-------------+
Explanation: 
Daniel made 1 sale in March 2020.
Elizabeth made 2 sales in 2020 and 1 sale in 2019.
Frank made 1 sale in 2019 but no sales in 2020.
```
---

### 💡 Idea

Use a `LEFT JOIN` to keep all sellers, while only matching orders made in 2020. Sellers with no matching order will have `NULL` for the order, so we can filter them out.

---

### 💻 Solution

```sql
SELECT s.seller_name
FROM Seller s
LEFT JOIN Orders o
    ON s.seller_id = o.seller_id
    AND o.sale_date >= '2020-01-01'
    AND o.sale_date < '2021-01-01'
WHERE o.order_id IS NULL
ORDER BY s.seller_name ASC;
```

---

### 🛠️ How It Works

1. Start with all sellers using `Seller`.
2. `LEFT JOIN` only matches their orders from 2020.
3. Sellers without any matching 2020 order get `NULL` for `order_id`.
4. Keep only those sellers using `WHERE o.order_id IS NULL`.
5. Sort the result by `seller_name` in ascending order.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(processes sellers and matching orders)*

**Space Complexity:** `O(n)` *(for the join and intermediate results)*
