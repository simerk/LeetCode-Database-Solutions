## 🚀 607. Sales Person

### 📖 Problem

Write a solution to find the names of all the salespersons who did not have any orders related to the company with the name **"RED"**.

Return the result table in **any order**.

---

### 📝 Example

```text
Input:

+----------+------+--------+-----------------+------------+    +--------+--------+----------+    +----------+------------+--------+----------+--------+
| sales_id | name | salary | commission_rate | hire_date  |    | com_id | name   | city     |    | order_id | order_date | com_id | sales_id | amount |
+----------+------+--------+-----------------+------------+    +--------+--------+----------+    +----------+------------+--------+----------+--------+
| 1        | John | 100000 | 6               | 4/1/2006   |    | 1      | RED    | Boston   |    | 1        | 1/1/2014   | 3      | 4        | 10000  |
| 2        | Amy  | 12000  | 5               | 5/1/2010   |    | 2      | ORANGE | New York |    | 2        | 2/1/2014   | 4      | 5        | 5000   |
| 3        | Mark | 65000  | 12              | 12/25/2008 |    | 3      | YELLOW | Boston   |    | 3        | 3/1/2014   | 1      | 1        | 50000  |
| 4        | Pam  | 25000  | 25              | 1/1/2005   |    | 4      | GREEN  | Austin   |    | 4        | 4/1/2014   | 1      | 4        | 25000  |

+------+

According to orders 3 and 4 in the Orders table, it is easy to tell that only salesperson John and Pam have sales to company RED, so we report all the other names in the table salesperson.
```

---

### 💡 Idea

Instead of joining all three tables, we only need to identify the `sales_id` values that have placed an order for the company **'Red'**. Then, we simply exclude those `sales_id`s from the **SalesPerson** table using `NOT IN`.

This approach is shorter, more efficient, and avoids an unnecessary join with the `SalesPerson` table inside the subquery.

---

### 💻 Solution

```sql
SELECT s.name
FROM SalesPerson s
WHERE s.sales_id NOT IN (
    SELECT o.sales_id
    FROM Orders o
    INNER JOIN Company c
    ON c.com_id = o.com_id
    WHERE c.name = 'Red'
);
```

---

### 🛠️ How It Works

1. Join the **Orders** and **Company** tables.
2. Filter the orders where the company name is **'Red'**.
3. The subquery returns the `sales_id` of every salesperson who has sold to **Red**.
4. The outer query selects all salespersons whose `sales_id` is **not** in that list.
5. The final result contains only the salespersons who have never sold to **Red**.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(depends on table size and indexing)*

**Space Complexity:** `O(n)` *(stores the list of `sales_id`s returned by the subquery)*
