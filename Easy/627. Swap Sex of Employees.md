## 🚀 627. Swap Sex of Employees

### 📖 Problem

Write a solution to swap all `'f'` and `'m'` values (i.e., change all `'f'` values to `'m'` and vice versa) with a **single update statement** and no intermediate temporary tables.

Note that you must write a single update statement, **do not** write any select statement for this problem.

---

### 📝 Example
```text
Input: 
Salary table:
+----+------+-----+--------+
| id | name | sex | salary |
+----+------+-----+--------+
| 1  | A    | m   | 2500   |
| 2  | B    | f   | 1500   |
| 3  | C    | m   | 5500   |
| 4  | D    | f   | 500    |
+----+------+-----+--------+
Output: 
+----+------+-----+--------+
| id | name | sex | salary |
+----+------+-----+--------+
| 1  | A    | f   | 2500   |
| 2  | B    | m   | 1500   |
| 3  | C    | f   | 5500   |
| 4  | D    | m   | 500    |
+----+------+-----+--------+
Explanation: 
(1, A) and (3, C) were changed from 'm' to 'f'.
(2, B) and (4, D) were changed from 'f' to 'm'.
```
---

### 💡 Idea

The goal is to **swap the values of `'m'` and `'f'`** in the `sex` column without using a temporary table or multiple update statements.

We can use a `CASE` expression inside a single `UPDATE` statement to replace:
- `'m'` with `'f'`
- `'f'` with `'m'`

---

### 💻 Solution

```sql
UPDATE Salary
SET sex = CASE
    WHEN sex = 'm' THEN 'f'
    ELSE 'm'
END;
```

---

### 🛠️ How It Works

1. Update every row in the `Salary` table.
2. Use a `CASE` expression to check the current value of `sex`.
3. If the value is `'m'`, change it to `'f'`.
4. Otherwise, change `'f'` to `'m'`.
5. The update is performed in a single SQL statement.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(updates each row once)*

**Space Complexity:** `O(1)` *(no additional storage required)*
