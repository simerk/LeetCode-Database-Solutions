## 🚀 1303. Find the Team Size 🔒

### 📖 Problem

Write a solution to find the team size of each of the employees.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Employee Table:
+-------------+------------+
| employee_id | team_id    |
+-------------+------------+
|     1       |     8      |
|     2       |     8      |
|     3       |     8      |
|     4       |     7      |
|     5       |     9      |
|     6       |     9      |
+-------------+------------+
Output: 
+-------------+------------+
| employee_id | team_size  |
+-------------+------------+
|     1       |     3      |
|     2       |     3      |
|     3       |     3      |
|     4       |     1      |
|     5       |     2      |
|     6       |     2      |
+-------------+------------+
Explanation: 
Employees with Id 1,2,3 are part of a team with team_id = 8.
Employee with Id 4 is part of a team with team_id = 7.
Employees with Id 5,6 are part of a team with team_id = 9.
```
---

### 💡 Idea

Count how many employees belong to each `team_id`, then join that count back to the `Employee` table so every employee gets their team's size.

---

### 💻 Solution

```sql
SELECT employee_id,
COUNT(*) OVER (PARTITION BY team_id) AS team_size
FROM Employee;
```

---

### 🛠️ How It Works

1. `PARTITION BY team_id` groups employees by their team.
2. `COUNT(*)` counts the employees within each team.
3. The window function keeps every employee row while adding its corresponding team size.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(counts employees within each team)*

**Space Complexity:** `O(n)` *(window-function processing)*
