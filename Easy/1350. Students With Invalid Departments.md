## 🚀 1350. Students With Invalid Departments 🔒

### 📖 Problem

Find the id and the name of all students who are enrolled in departments that no longer exist.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Students table:                          Departments table:
+------+----------+---------------+      +------+--------------------------+
| id   | name     | department_id |      | id   | name                     |
+------+----------+---------------+      +------+--------------------------+
| 23   | Alice    | 1             |      | 1    | Electrical Engineering   |
| 1    | Bob      | 7             |      | 7    | Computer Engineering     |
| 5    | Jennifer | 13            |      | 13   | Bussiness Administration |
| 2    | John     | 14            |      +------+--------------------------+
| 4    | Jasmine  | 77            |
| 3    | Steve    | 74            |
| 6    | Luis     | 1             |
| 8    | Jonathan | 7             |
| 7    | Daiana   | 33            |
| 11   | Madelynn | 1             |
+------+----------+---------------+
Output: 
+------+----------+
| id   | name     |
+------+----------+
| 2    | John     |
| 7    | Daiana   |
| 4    | Jasmine  |
| 3    | Steve    |
+------+----------+
Explanation: 
John, Daiana, Steve, and Jasmine are enrolled in departments 14, 33, 74, and 77 respectively.
department 14, 33, 74, and 77 do not exist in the Departments table.
```
---

### 💡 Idea

Use a `LEFT JOIN` between `Students` and `Departments`. Students whose `department_id` has no matching department will have a `NULL` department ID, so we can filter those records.

---

### 💻 Solution

```sql
SELECT s.id, s.name FROM Students s
LEFT JOIN Departments d ON s.department_id = d.id
WHERE d.id IS NULL;
```

---

### 🛠️ How It Works

1. Start with all students.
2. Match each student's `department_id` with `Departments.id`.
3. If no department exists, the joined `d.id` becomes `NULL`.
4. Keep only those students with `d.id IS NULL`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(joins students with the department table)*

**Space Complexity:** `O(n)` *(stores the join results)*
