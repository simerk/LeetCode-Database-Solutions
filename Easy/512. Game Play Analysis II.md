## 🚀 512. Game Play Analysis II 🔒

### 📖 Problem

Write a solution to report the **device** that is first logged in for each player.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output: 
+-----------+-----------+
| player_id | device_id |
+-----------+-----------+
| 1         | 2         |
| 2         | 3         |
| 3         | 1         |
+-----------+-----------+
```

---

### 💡 Idea

We need to find the **first login date** for each player.

Since the first login corresponds to the **earliest (`MIN`) `event_date`** for every player, we can group the records by `player_id` and use the `MIN()` aggregate function to retrieve the earliest date.

---

### 💻 Approach 1: Window Function (`FIRST_VALUE`) *(Recommended)*

```sql
SELECT DISTINCT player_id,
FIRST_VALUE(device_id) OVER (PARTITION BY player_id ORDER BY event_date) AS device_id
FROM Activity;
```

### 🛠️ How It Works

1. `PARTITION BY player_id` processes each player's records separately.
2. `ORDER BY event_date` sorts each player's logins from earliest to latest.
3. `FIRST_VALUE(device_id)` returns the device used during the first login.
4. `DISTINCT` removes duplicate rows so each player appears only once.

---

### 💻 Approach 2: Aggregation + Join

```sql
SELECT a.player_id, a.device_id
FROM Activity a
JOIN (
    SELECT player_id,
    MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id) b
ON a.player_id = b.player_id
AND a.event_date = b.first_login;
```

### 🛠️ How It Works

1. The subquery finds the earliest (`MIN`) login date for each player.
2. Join it back with the `Activity` table using both `player_id` and `event_date`.
3. Return the corresponding `device_id` for that first login.

---

### ⭐ Recommended Approach

The **Window Function (`FIRST_VALUE`)** approach is recommended because it directly retrieves the first device without requiring an additional join, making the query shorter and easier to read.

---

### ⏱️ Complexity Comparison

| Approach | Time Complexity | Space Complexity |
|----------|-----------------|------------------|
| Window Function (`FIRST_VALUE`) | `O(n log n)` | `O(n)` |
| Aggregation + Join | `O(n)` | `O(n)` |
