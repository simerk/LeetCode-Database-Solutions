## 🚀 1280. Students and Examinations

### 📖 Problem

Write a solution to find the number of times each student attended each exam.

Return the result table ordered by `student_id` and `subject_name`.

---

### 📝 Example
```text
Input: 
Students table:                      Subjects table:
+------------+--------------+        +--------------+
| student_id | student_name |        | subject_name |
+------------+--------------+        +--------------+
| 1          | Alice        |        | Math         |
| 2          | Bob          |        | Physics      |
| 13         | John         |        | Programming  |
| 6          | Alex         |        +--------------+
+------------+--------------+
Examinations table:
+------------+--------------+
| student_id | subject_name |
+------------+--------------+
| 1          | Math         |
| 1          | Physics      |
| 1          | Programming  |
| 2          | Programming  |
| 1          | Physics      |
| 1          | Math         |
| 13         | Math         |
| 13         | Programming  |
| 13         | Physics      |
| 2          | Math         |
| 1          | Math         |
+------------+--------------+
Output: 
+------------+--------------+--------------+----------------+
| student_id | student_name | subject_name | attended_exams |
+------------+--------------+--------------+----------------+
| 1          | Alice        | Math         | 3              |
| 1          | Alice        | Physics      | 2              |
| 1          | Alice        | Programming  | 1              |
| 2          | Bob          | Math         | 1              |
| 2          | Bob          | Physics      | 0              |
| 2          | Bob          | Programming  | 1              |
| 6          | Alex         | Math         | 0              |
| 6          | Alex         | Physics      | 0              |
| 6          | Alex         | Programming  | 0              |
| 13         | John         | Math         | 1              |
| 13         | John         | Physics      | 1              |
| 13         | John         | Programming  | 1              |
+------------+--------------+--------------+----------------+
Explanation: 
The result table should contain all students and all subjects.
Alice attended the Math exam 3 times, the Physics exam 2 times, and the Programming exam 1 time.
Bob attended the Math exam 1 time, the Programming exam 1 time, and did not attend the Physics exam.
Alex did not attend any exams.
John attended the Math exam 1 time, the Physics exam 1 time, and the Programming exam 1 time.
```
---


### 💡 Idea

The goal is to report the number of times each student attended each exam.

Since every student should appear for **every subject**, we first generate all possible **student-subject combinations** using a `CROSS JOIN`. Then, we `LEFT JOIN` the `Examinations` table to count how many times each student attended each subject's exam.

---

## 💻 Solution

```sql
SELECT
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e
ON s.student_id = e.student_id
AND sub.subject_name = e.subject_name
GROUP BY s.student_id, s.student_name, sub.subject_name
ORDER BY s.student_id, sub.subject_name;
```

---

### 🛠️ How It Works

1. Use a `CROSS JOIN` to generate every possible student-subject combination.
2. `LEFT JOIN` the `Examinations` table using both `student_id` and `subject_name`.
3. Match the examination records for each student and subject.
4. Group the results by student and subject.
5. Use `COUNT()` to count the number of matching examination records.
6. Students who never attended an exam for a subject will have a count of **0**.

---

### ⏱️ Complexity

**Time Complexity:** `O(s × sub + e)`  
*(where `s` = number of students, `sub` = number of subjects, and `e` = number of examination records)*

**Space Complexity:** `O(s × sub)` *(stores all student-subject combinations)*
