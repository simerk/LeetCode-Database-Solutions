## 🚀 613. Shortest Distance in a Line 🔒

### 📖 Problem

Find the shortest distance between any two points from the `Point` table.

---

### 📝 Example

```text
Input: 
Point table:
+----+
| x  |
+----+
| -1 |
| 0  |
| 2  |
+----+
Output: 
+----------+
| shortest |
+----------+
| 1        |
+----------+
Explanation: The shortest distance is between points -1 and 0 which is |(-1) - 0| = 1.
```
---

### 💡 Idea

We need to find the **minimum distance between any two points** on a line.

Since the points are one-dimensional, the distance is simply the **absolute difference** between their `x` values. We can compare each point with every other point and find the minimum difference.

---

### 💻 Solution

```sql
SELECT MIN(ABS(p1.x - p2.x)) AS shortest
FROM Point p1
JOIN Point p2 ON p1.x != p2.x;
```

---

### 🛠️ How It Works

1. Self-join the `Point` table to compare different points.
2. Calculate the absolute difference between their `x` values.
3. Use `MIN()` to find the smallest distance.

---

### ⏱️ Complexity

**Time Complexity:** `O(n²)` *(compares every pair of points)*

**Space Complexity:** `O(n²)` *(the self-join can generate up to `n²` pairs)*
