## 🚀 3436. Find Valid Emails

### 📖 Problem

Write a solution to find all the **valid email addresses**. A valid email address meets the following criteria:

- It contains exactly one `@` symbol.
- It ends with `.com`.
- The part before the `@` symbol contains only **alphanumeric** characters and **underscores**.
- The part after the `@` symbol and before `.com` contains a domain name **that contains only letters**.
  
Return the result table ordered by `user_id` in **ascending order**.

---

### 📝 Example
```text
Input:
Users table:
+---------+---------------------+
| user_id | email               |
+---------+---------------------+
| 1       | alice@example.com   |
| 2       | bob_at_example.com  |
| 3       | charlie@example.net |
| 4       | david@domain.com    |
| 5       | eve@invalid         |
+---------+---------------------+
Output:
+---------+-------------------+
| user_id | email             |
+---------+-------------------+
| 1       | alice@example.com |
| 4       | david@domain.com  |
+---------+-------------------+
Explanation:
• alice@example.com is valid because it contains one @, alice is alphanumeric, and example.com starts with a letter and ends with .com.
• bob_at_example.com is invalid because it contains an underscore instead of an @.
• charlie@example.net is invalid because the domain does not end with .com.
• david@domain.com is valid because it meets all criteria.
• eve@invalid is invalid because the domain does not end with .com.
Result table is ordered by user_id in ascending order.
```
---

### 💡 Idea

The goal is to find all users whose email addresses follow the required format.

We use the `REGEXP` operator to validate the email pattern by checking the username, domain name, and domain extension.

---

## 💻 Solution

```sql
SELECT
    user_id,
    email
FROM Users
WHERE email REGEXP '^[A-Za-z0-9_]+@[A-Za-z]+\\.com$'
ORDER BY user_id;
```

---

### 🛠️ How It Works

1. Use the `REGEXP` operator to filter only the email addresses that match the required pattern.
2. Match the username using `[A-Za-z0-9_]+`, allowing only letters, digits, and underscores before the `@`.
3. Match the domain name using `[A-Za-z]+`, ensuring it contains only letters.
4. Match the literal `.com` extension using `\\.com`.
5. Return the valid email addresses ordered by `user_id`.

---

### 🔄 Other Approaches

- ✅ `REGEXP` *(recommended approach)*
- ✅ Multiple `LIKE()` and string functions *(more complex and less efficient)*

---

### ⏱️ Complexity

**Time Complexity:** `O(n × m)`

*(`n` = number of rows, `m` = average email length)*

**Space Complexity:** `O(1)`
